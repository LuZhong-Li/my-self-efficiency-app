# 小李

> A local offline personal efficiency dashboard with macOS Liquid Glass UI.
> Run locally, store all data in JSON files, no database, no network requests.
> Contains schedule, media, development, fitness and diet modules.

只在你自己电脑上跑的个人工作台：**不登录、不联网、不上云、不装依赖**。
双击一个文件，浏览器打开十一个模块，所有数据存成本机一个 JSON 文件。

## 怎么跑

需要电脑上有 **Python 3**（3.8 以上都行）。

**Windows**：双击 `启动.cmd`。黑窗口起来后浏览器会自动打开界面，
**关掉黑窗口就等于停止程序**。

**macOS / Linux**：在项目目录执行

```bash
python3 app/服务.py
```

它会起一个只监听 `127.0.0.1` 的小服务，然后手动打开它打印出来的地址。

## 看效果 / 演示

开发用的这一份可以一键塞一套样例数据（任务、学习记录、训练、体重、
自媒体……全都铺在当前这个月），用来演示、截图、看界面效果：

这套数据是**跟着功能一起更新的**（2026-10-08 补过一轮），各模块都铺满了，
每一版新加的东西都能在里面看见：模块目标与自动生成的待办、游戏游玩记录与统计、
自媒体的账号 / 粉丝快照 / 爆款榜 / 废弃归档、开发工作的待办与 bug 五个状态、
待办和 bug 的归档抽屉、记账的分类预算与超支红边、债务、回收站，
以及**待办跨模块联动**——今日计划里同时有「今日计划自己的」「开发工作加进来的」
「游戏娱乐顺手加的」「模块目标自动生成的」四种来源标签，行上有高 / 中 / 低
优先级胶囊，首页和今日计划的进度、数字都是同一份数据算出来的。

双击 `演示数据.cmd`，按数字选：**1** 载入示例数据（你现在这份会先存一份
快照，随时能还原）、**2** 还原回载入之前、**3** 只看现在有哪些数据、
**4** 载入到「现在正开着的那个小李」。

它默认只动**这份代码自己的** `数据\` 目录，不会碰你日常在用的那一份。
`同步到小李.cmd` 也不会把它（`演示数据.cmd` 和 `tools\`）带到日常那份去——
那套工具只服务开发版，免得哪天在日常那份里手一滑，把真实数据换成演示数据。
载入前的数据会存成 `备份\保留-演示前-*.json`（标着「长期保留」，自动清理
会跳过它），在「数据与设置 → 导入恢复」里也能选它还原。

另外：仓库和日常那份可以同时开着。启动时会先看端口上那个是不是「自己
这一份」，不是就往后找一个空端口（8766、8767……），绝不会把浏览器指到
另一份的旧界面上——这样你在开发版里改的东西一定能看见。

## 数据在哪

一份数据 = **一个文件夹**，里面就一个数据文件：`数据/默认/数据.json`（第一次运行时自动创建）。

```
数据/                    ← 数据根目录（多套数据就并排放在这儿）
  当前数据集.txt         现在用哪一份（就一行字，坏了也能自己改）
  默认/                  ← 一个数据集 = 一个文件夹，整份能搬走
    数据.json           全部数据就这一个文件，随时可以复制走
    attachments/        图片备注，按模块分成 finance/（记账）、buglog/（bug 截图）、
                        progress/（项目进展）、today_plan/、dev_project/、dev_todo/、
                        study_record/、study_item/、fitness/、game/、game_record/ 几个子文件夹
    备份/               每天首次打开自动存一份，保留最近若干份
      _最近一次.json     每次保存前的上一版
    导出/               手动导出的备份文件、打包好的数据集 zip
    日志/运行.log       启动、备份、导入这些关键事件的流水
  工作/                 另一套数据（在设置页点「用这份」就切过去）
```

**多套数据**：设置页最上面那张「数据集」卡片能新建、切换、重命名、导出（打包成 zip，
连着图片一起走）。同一时间只用一份，切换之后页面会重载；状态栏一直写着你在用哪一份。
老版本（数据直接躺在 `数据/` 下）第一次运行时会被自动搬进 `数据/默认/`，
内容一个字不动，搬了哪几样会写进日志。

想换地方放数据（比如另一块盘），设环境变量就行：

```bash
XIAOLI_DATA_ROOT=D:\我的小李数据 python app/服务.py
```

那是「数据根目录」（里面还是一份一个文件夹）。要是只想指一份数据、不要多数据集那一套，
用老变量 —— 这时数据集功能整体关着，那个目录就按「就是这一份」理解
（`自检.py` 和所有浏览器测试走的就是这一条）：

```bash
XIAOLI_DATA_DIR=D:\我的小李数据 python app/服务.py
```

## 怎么更新

如果「日常用的那份」和「开发用的这份」是分开的两个目录，
把代码同步过去就行——仓库里的 `同步到小李.cmd` 就是干这个的（不会动你的数据）。

## 自检

双击 `自检.cmd`（或在终端跑 `python tests/自检.py`）。它会在一个**临时目录**里
自己起一个服务，把 165 项关键检查过一遍——接口、修订号、写入锁、来源校验、备份、
长期保留、导出导入往返、清空快照、运行日志、图片附件的上传/取回/删除/越界拦截、
老数据的字段补齐与状态改名、数据集（老布局自动搬迁 / 切换 / 防串数据 / 导出 zip）、
零外链。**不会碰你正在用的数据。**

## 几条设计上的选择

- **一个 JSON 文件，不装数据库**：个人数据量小，一个文件最好备份、最好搬走。
- **只用 Python 标准库**：不用 pip 装任何东西，`python app/服务.py` 就能跑。
- **前端不引框架**：不引 CDN、不引在线字体和图标，断网完全正常。
  唯一一个第三方文件是**本地放着**的
  [SortableJS](https://github.com/SortableJS/Sortable) 1.15.7（MIT，44KB），
  用来做开发工作页的项目卡片拖拽排序；没有它也能正常用，只是卡片拖不动。
  它的许可证随文件一起放在 `app/web/lib/sortable.LICENSE`。
- **写接口只认本机页面**：别的网站在浏览器里也能往 `127.0.0.1` 发请求，
  所以写接口会看来源，不是本机页面的一律拒掉。
- **删除先进回收站**：手滑删了能捞回来。
- **图片不进主数据文件**：记账、bug 登记、项目进展、今日计划、开发待办、学习记录、
  学习对象、训练打卡、游戏、游玩记录的截图都存在 `数据\attachments\` 里，
  `数据.json` 只记相对路径 —— 几张截图不会把数据文件撑大，备份、换盘都还是「一个目录」。
  图片在点「保存」时才落盘；「彻底删除」一条记录时要不要连图片一起删，
  在「数据与设置 → 图片附件」里选（默认保留）。
- **截图直接 Ctrl+V 贴**：任何带图片区的弹窗里，截图（Win+Shift+S）之后按
  Ctrl+V 就把剪贴板里那张图收进附件区，不用先另存成文件再点「选择文件」；
  点按钮选本地文件那条路照旧。剪贴板里同时夹着文字（从 Excel、网页复制的）
  时不抢这次粘贴，文字照常落进输入框。
- **录入统一走弹窗**：卡片上只留一个蓝色添加按钮，点开弹窗填、保存才写数据；
  编辑复用同一个弹窗回填。各模块共用一套字段表和一套弹窗底层
  （`item-form.js` + `item-dialog.js`），字段 / 校验 / 写回只有一份实现；
  模块目标那个弹窗也是从这里加的（只是它没有图片区，存的也不是普通表）。
- **目标和待办分开**：健身 / 学习 / 饮食的**模块目标**是模块级配置
  （存在 `moduleGoals` 里），从目标拆出来的单次执行项才写进 `tasks`；
  开着自动生成时，进「今日计划」按规则生成当天的待办，行上标着来源模块，
  正文照样能改、能勾、能删；删目标只删配置，已经生成的待办一条不动。
  首页那张「目标总览」只是把三个模块的目标读出来现算进度、点一下跳回模块，
  自己不存数据、也不能在卡片上改目标（改目标仍然回各模块页）。
- **一条待办只有一份**：今日计划、首页总览、开发工作里的项目待办读的都是
  `tasks` 里**同一条记录**，打勾和改状态只走 `task-actions.js` 那两个函数，
  所以「这边做完那边还没做」这种不一致从根上就不会发生。项目待办默认只属于
  那个项目，勾上尾部那个「今日计划」才会同时出现在今日计划和首页（数据只有一份，
  不是复制过去的）；**删除只能在原模块删** —— 今日计划、首页、月历对外来的待办
  只给「移出今日计划」和「回项目」，不给删除按钮。
- **累计时长不手填**：游戏娱乐的「累计 X 小时」是把 `gameRecords` 里这款游戏的
  游玩记录加起来算的（老数据里手填的 `hours` 也一起算，不会丢），
  一个数只有一个来源，省得手填的和实际记的对不上。
- **输入就自动保存**：单值字段（备忘、三餐、每周安排、标语…）停笔即存；
  行内编辑边打字边静默保存，点「取消」会退回编辑前的样子；
  表单填了一半没提交，关窗口前浏览器会拦一下。
- **筛选只影响显示**：开发工作页的关键词/状态筛选不会动数据，
  被筛掉的项目在拖拽排序时也保持原位。
- **两个窗口不会互相覆盖**：数据里带修订号，写盘前先对一遍，对不上就拒收、**绝不覆盖**；
  后端写盘时还加一把 `数据.lock` 写入闸（超 10 秒的残留锁启动时自动清），挡住并发写。
  撞上冲突时本窗口的改动**一直留着**，弹窗让你选：导出本窗口改动备份 / 刷新并加载最新数据 /
  取消；要丢也是你自己点「加载最新」才丢。窗口之间用浏览器自带的 `BroadcastChannel` 互相
  知会，本窗口有没落盘的内容时也会先问一句再刷新，不擅自把正在编辑的东西冲掉。
