# 开发工作改版 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「问题 / bug」和「最近进展」补齐：bug 能写详细描述、标关联模块、
扩状态、带截图；进展能带图、能改；列表点条目展开看详情与截图；顶部有统计与筛选。

**Architecture:** 图片能力直接用第 24 节那套附件组件（`attachment.js` 一行没改，
只多了 `progress` 这个 module）。新的纯逻辑放 `app/web/dev-calc.js`（Node 直接单测），
页面 `app/web/dev.js` 只管画和接事件；服务端 `migrate()` 负责把老字段补齐、老状态改名。

**Tech Stack:** 原生 HTML + CSS + ES 模块（无框架、无构建、零外链）；
弹窗用现成的 `openDialog`；Python 标准库小服务；Node 跑纯逻辑单测。

**Spec:** `docs/superpowers/specs/2026-10-07-开发工作改版-design.md`

## Global Constraints

- **零外链**：`.html` / `.css` / `.js` 里不能出现 `http(s)://`（`tests/自检.py` 会扫）。
- **不装依赖**：Python 标准库 + 本机 Node v24，不建 `node_modules`。
- **事件不挂公共 `#view`**：一律 `bindFresh(root, { click, submit, change, input })`。
- **图片先落盘、JSON 后落盘**；「取消」时一个字节都不能留下（沿用第 24 节）。
- **筛选只影响显示**：动数据的只有增删改。
- **删除先进回收站**；图片只在「彻底删除」时按设置决定跟不跟着删。
- **注释和提交信息用中文**，说清「为什么」。
- 每个任务结束时：`python tests\自检.py` 全过、控制台 0 条 error / warning。
