# 自媒体模块改版 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「自媒体」从选题待办升级成多账号 + 数据看板 + 排期日历 + 内容流水线，
数据全部落在本地 `数据.json`，不影响其它九个模块。

**Architecture:** 算数部分抽成无依赖的纯模块 `app/web/media-calc.js`（Node 直接单测），
页面 `app/web/media.js` 只管画和接事件。数据新增两个顶层键 `mediaAccounts` /
`mediaFollowers`，`contents` 扩字段但不搬家。首页卡片走 `home-view.js` 的纯逻辑。

**Tech Stack:** 原生 HTML + CSS + ES 模块（无框架、无构建、零外链）；手写 SVG 折线图；
本地 SortableJS 1.15.7（拖拽）；Python 标准库小服务；Node 跑纯逻辑单测。

**Spec:** `docs/superpowers/specs/2026-10-07-自媒体改版-design.md`（实施前先读一遍）

## Global Constraints

- **零外链**：`.html` / `.css` / `.js` 里不能出现 `http(s)://`，`tests/自检.py` 的
  `check_no_external()` 会扫。
- **不装依赖**：只跑 Python 标准库 + 本机 Node v24（`node tests\某文件.mjs`，不需要
  `package.json`、不要建 `node_modules`）。
- **事件不挂公共 `#view`**：一律 `bindFresh(root, { click, submit, change, input })`。
- **改动即保存**：明确动作 `touch(true)`；连续输入 `touch(false, true)`（静默，不重画，
  否则光标会跳）；只挂 `change`/`input` 的筛选框要加进 `store.js` 的 `AUTOSAVE_FIELDS`。
- **删除一律进回收站**：`moveToTrash(表名, 行, 显示文字)`。
- **颜色只用 CSS 变量**（平台内容色除外，见 spec §9）。
- **注释和提交信息用中文**，说清「为什么」。
- 每个任务结束时工作区要能跑：`python tests\自检.py` 全过、控制台 0 条 error / warning。

**关键算法（照抄，这是最容易算错的地方）:**

```js
export function followersAt(account, contents, snapshots, date) {
  const mine = contentsOfAccount(account, contents);
  const snaps = (snapshots || [])
    .filter((s) => s.accountId === account.id && s.date && s.date <= date)
    .sort((a, b) => (a.date < b.date ? -1 : a.date > b.date ? 1 : 0));
  const last = snaps[snaps.length - 1];
  const base = last ? Number(last.count) || 0 : Number(account.baseFollowers) || 0;
  const since = last ? last.date : "";
  return (
    base +
    mine
      .filter((c) => c.publishDate && c.publishDate <= date && (!since || c.publishDate > since))
      .reduce((sum, c) => sum + (Number(c.fansGain) || 0), 0)
  );
}
```

`isHit` 只在「已发布且填了播放的作品 ≥ 3 条、平均 > 0」时才有结论。
`weekRangeOf` 的周一为一周开头，`prevEnd` = `start` 的前一天。
