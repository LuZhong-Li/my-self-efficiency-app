# 首页总览改版（双视图）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把首页从「所有模块卡片平铺」改成【简洁 / 完整】双视图：简洁模式首屏只给今日进度、今日待办和财务摘要，高频模块卡默认展示、次要模块折叠收纳；完整模式保留原来的全卡片布局。视图选择存进数据文件，刷新和换窗口都不重置。

**Architecture:** 「哪个视图显示哪些卡、卡片正面写什么、hover 提示写什么、今天进度怎么算」全部抽进一个新的纯逻辑模块 `app/web/home-view.js`（只吃数据、吐结果，不碰 DOM、不碰 store），用 Node 直接跑单元测试；`home.js` 退化成两个视图的模板 + 事件，`store.js` 只多两个和 `themeOf` / `setSkin` 并列的存取函数。数据结构和 `数据.json` 不动，只多一个 `settings.homeView` 字段。

**Tech Stack:** 原生 HTML + CSS + ES 模块（无框架、无构建、零外链）；Python 标准库小服务；测试用 Node（`tests/首页视图.test.mjs`，纯逻辑层）与 Python（`tests/自检.py`，接口层回归）。

**Spec:** `docs/superpowers/specs/2026-10-07-首页总览-design.md`（本计划按它写；实施前先读一遍，尤其 §1 的决定表和 §10 那条分歧的结论）

## Global Constraints

- **零外链**：界面文件（`.html` / `.css` / `.js`）里不能出现任何 `http(s)://` 链接，不引 CDN、在线字体、图标库。`tests/自检.py` 的 `check_no_external()` 会扫，出现一条就算失败。
- **不装依赖**：跑 App 只用 Python 标准库；Node 只用来跑 `tests/*.test.mjs`（本机 v24，`node 文件名` 直接可跑，不需要 `package.json`，也不要新建 `node_modules`）。
- **图标一律手写 SVG**：新图标加进 `app/web/icons.js` 的 `PATHS`，`stroke="currentColor"`，不用 emoji、不用图标字体（`docs/superpowers/specs/2026-10-07-记账-design.md` §1 定的规矩）。按钮文案里的 emoji 也按这条换掉。
- **颜色只用 CSS 变量**：主色 `var(--accent)`、警告 `var(--warn)` / `var(--warn-bg)` / `var(--warn-line)`、危险 `var(--err)`；不在组件里写死颜色，四套皮肤（`glass` / 缺省 / `notebook` / `neo`）× 深浅两色都不能破相。
- **样式守项目规范**：圆角 `--r-lg` / `--r-md` / `--r-sm`，阴影 `--shadow` / `--shadow-lift`，间距是 8 的倍数。
- **事件不挂公共 `#view`**：一律 `bindFresh(root, { click, change, input })`（`app/web/ui.js`）。
- **改动即保存**：明确动作走 `touch(true)`；连续输入走 `touch(false, true)` 静默保存。
- **`settings` 里的偏好跟着数据走**：视图和主题、皮肤一样存 `store.data.settings`，不用 `localStorage`——换数据文件、两个窗口同步都不用另做一套。
- **注释和提交信息用中文**，风格照现有文件（说清「为什么」，不只说「做了什么」）。
- 每个任务结束时工作区要能跑：`python tests\自检.py` 必须 `通过 26 项，失败 0 项`，浏览器控制台 0 条 error / warning。

### Task 1: 首页纯逻辑（`home-view.js`）+ 单测

**Files:**
- Create: `app/web/home-view.js`
- Create: `tests/首页视图.test.mjs`
- Modify: `app/web/modules.js`

**Interfaces:**
- Consumes: `SUMMARY_MODULES` / `moduleOf(id)`（`modules.js`）、`dayTotals` / `monthTotals`（`finance-calc.js`）、`fmtMoney`（`money.js`）、`upcoming` / `remainCents` / `dueState` / `daysUntil`（`debt-calc.js`）
- Produces:
  - `normalizeHomeView(raw) -> "simple" | "full"`（认不出的一律给 `"simple"`）
  - `rows(data, key) -> object[]`（认 `"finance.transactions"` 这种带点路径，缺键时给空数组，不抛）
  - `weekStartOf(today) -> "YYYY-MM-DD"`（那一天所在周的周一）
  - `todayTasks(tasks, today) -> task[]`（做完的排最后，其余按时间点）
  - `overdueTasks(data, today) -> task[]`（昨天及更早没做完的，日期从早到晚）
  - `HOME_TASK_LIMIT = 5`
  - `progressOf(data, today) -> { mine, total, done, open, untimed, percent, shown, hidden }`
  - `summaryOf(id, data, today) -> { main, sub, extra }`
  - `cardOf(id, data, today) -> { id, name, icon, main, sub, extra, tip }`
  - `cardsFor(view, data, today) -> { view, highlight, other }`
  - `hasData(id, data) -> boolean`、`otherVisibleIn(data) -> boolean`
  - `debtWarningOf(data, today) -> null | { level, itemId, name, remainCents, text, tip }`
  - `financeBriefOf(data, today) -> { hasAny, hasTodayExpense, expense, balance, debt }`
  - `financeTextOf(brief) -> { expenseLabel, expenseText, balanceLabel, balanceText }`

**说明（先说清两处口径）：**

1. `untimed`（待安排）沿用现有含义：今天没填时间点的条数，**不管做完没做完**——和现在首页那个数字一模一样，不改口径。
2. `summaryOf` 是 `home.js` 现有 `summary()` 原样搬过来的，只有一处文案微调：健身的 `sub` 从 `最近一次：2026-10-07` 改成 `最近一次训练：2026-10-07`（spec §2③ 的 hover 提示表就是这么写的）。两个视图共用同一份文案，所以完整模式那一行也会跟着变这两个字，这是有意的。

function deep(a, b) {
  if (a === b) return true;
  if (typeof a !== "object" || typeof b !== "object" || !a || !b) return false;
  const ka = Object.keys(a);
  const kb = Object.keys(b);
  if (ka.length !== kb.length) return false;
  return ka.every((k) => deep(a[k], b[k]));
}

import { fmtMoney } from "./money.js";

/** 按 "finance.transactions" 这种路径取一张表；缺键、类型不对都给空数组，不抛。 */
export function rows(data, key) {
  const parts = String(key).split(".");
  let holder = data || {};
  for (const part of parts.slice(0, -1)) {
    const next = holder ? holder[part] : null;
    if (!next || typeof next !== "object") return [];
    holder = next;
  }
  const list = holder ? holder[parts[parts.length - 1]] : null;
  return Array.isArray(list) ? list : [];
}

/** 那一天所在周的周一（本地日期，不走 UTC，免得时区把日子算歪） */
export function weekStartOf(today) {
  const [y, m, d] = String(today).split("-").map(Number);
  const dt = new Date(y, m - 1, d);
  dt.setDate(dt.getDate() - ((dt.getDay() + 6) % 7));
  const p = (n) => String(n).padStart(2, "0");
  return dt.getFullYear() + "-" + p(dt.getMonth() + 1) + "-" + p(dt.getDate());
}

function compareTasks(a, b) {
  if (Boolean(a.done) !== Boolean(b.done)) return a.done ? 1 : -1;
  const at = a.time || "99:99";
  const bt = b.time || "99:99";
  if (at !== bt) return at < bt ? -1 : 1;
  return (a.createdAt || "") < (b.createdAt || "") ? -1 : 1;
}

/** 今天那几条：做完的排最后，其余按时间点，没填时间点的排最后 */
export function todayTasks(tasks, today) {
  return (tasks || []).filter((t) => t && t.date === today).sort(compareTasks);
}

/** 昨天及更早没做完的，日期从早到晚 */
export function overdueTasks(data, today) {
  return rows(data, "tasks")
    .filter((t) => t && !t.done && t.date && t.date < today)
    .sort((a, b) => (a.date === b.date ? compareTasks(a, b) : a.date < b.date ? -1 : 1));
}

/** 今天的进度：总数 / 已完成 / 待安排 / 百分比，外加「列前 5 条、还剩几条」。
 *  待安排 = 今天没填时间点的条数（跟原来首页那个数字一个口径）。 */
export function progressOf(data, today) {
  const mine = todayTasks(rows(data, "tasks"), today);
  const done = mine.filter((t) => t.done).length;
  return {
    mine,
    total: mine.length,
    done,
    open: mine.length - done,
    untimed: mine.filter((t) => !t.time).length,
    percent: mine.length ? Math.round((done / mine.length) * 100) : 0,
    shown: mine.slice(0, HOME_TASK_LIMIT),
    hidden: Math.max(0, mine.length - HOME_TASK_LIMIT),
  };
}

function newest(items) {
  return items.slice().sort((a, b) => ((a.date || "") < (b.date || "") ? 1 : -1))[0];
}

/** 债务预警：只看已逾期或 7 天内到期的未结清债务，取到期最近的一笔；
 *  没有就返回 null（首页那一行整个不渲染，不留空白）。 */
export function debtWarningOf(data, today) {
  const first = upcoming(rows(data, "debt.items"), today, 7)[0];
  if (!first) return null;
  const remain = remainCents(first);
  const days = daysUntil(first.dueDate, today);
  const late = dueState(first, today) === "overdue";
  return {
    level: late ? "overdue" : "soon",
    itemId: first.id,
    name: first.name,
    remainCents: remain,
    text: `${late ? "已逾期" : "近 7 天待还"}：${first.name} ${fmtMoney(remain)}`,
    tip: late ? `已经过了 ${Math.abs(days)} 天` : days === 0 ? "今天到期" : `${days} 天后到期`,
  };
}

/** 财务摘要：今日支出 / 本月结余 + 一条债务预警（没有就是 null） */
export function financeBriefOf(data, today) {
  const txs = rows(data, "finance.transactions");
  const day = dayTotals(txs, today);
  const month = monthTotals(txs, today.slice(0, 7));
  return {
    hasAny: txs.length > 0,
    hasTodayExpense: day.expenseCents > 0,
    expense: fmtMoney(day.expenseCents),
    balance: fmtMoney(month.balanceCents),
    debt: debtWarningOf(data, today),
  };
}

/** 财务摘要那两格要显示的字：没数据时说人话，不显示 ¥0.00，也不留空壳 */

    balanceLabel: "本月结余",

/** 一张卡片的内容：main 是卡片正面那一行，sub / extra 是完整模式用的第二行，
 *  tip 是鼠标悬浮提示（正面只留核心数字，次要信息都进这里）。 */
export function summaryOf(id, data, today) {
  if (id === "media") {
    const items = rows(data, "contents");
    const n = (s) => items.filter((x) => x.status === s).length;
    return {
      main: `${n("待发布")} 条待发布`,
      sub: items.length
        ? `想法 ${n("想法")} · 写作中 ${n("写作中")} · 已发布 ${n("已发布")}`
        : "还没有内容",
    };
  }
  if (id === "dev") {
    const running = rows(data, "projects").filter((p) => p.status === "进行中").length;
    const open = rows(data, "issues").filter((i) => !["已解决", "已关闭"].includes(i.status)).length;
    return { main: `${running} 个项目进行中`, sub: `未解决 bug ${open} 条` };
  }
  if (id === "study") {
    const all = rows(data, "studies");
    const start = weekStartOf(today);
    const week = all
      .filter((s) => s.date >= start && s.date <= today)
      .reduce((sum, s) => sum + (Number(s.minutes) || 0), 0);
    const pending = all.filter((s) => !s.reviewed).length;
    const last = newest(all);
    return {
      main: `本周学了 ${week} 分钟`,
      sub: pending
        ? `待复习 ${pending} 条`
        : last
        ? `最近：${last.date} ${last.content || ""}`.trim()
        : "还没有学习记录",
    };
  }
  if (id === "finance") {
    const txs = rows(data, "finance.transactions");
    const day = dayTotals(txs, today);
    const totals = monthTotals(txs, today.slice(0, 7));
    const debt = debtWarningOf(data, today);
    return {
      main: `今日支出 ${fmtMoney(day.expenseCents)}`,
      sub: txs.length ? `本月结余 ${fmtMoney(totals.balanceCents)}` : "还没有记账",
      extra: debt ? debt.text : "",
    };
  }
  if (id === "fitness") {
    const logs = rows(data, "workoutLogs");
    const start = weekStartOf(today);
    const days = new Set(
      logs.filter((l) => l.date >= start && l.date <= today).map((l) => l.date)
    );
    const last = newest(logs);
    return {
      main: `本周练了 ${days.size} 次`,
      sub: last ? `最近一次训练：${last.date}` : "还没有训练记录",
    };
  }
  if (id === "diet") {

    const water = rows(data, "water").find((w) => w.date === today);
    const eaten = meal

      : 0;

    return { main: `今天记了 ${eaten} 餐`, sub: `喝水 ${cups} 杯` };
  }
  const playing = rows(data, "games").filter((g) => g.status === "在玩");
  return {
    main: playing.length ? `在玩 ${playing.length} 款` : "没有在玩的游戏",
    sub: playing.length ? playing.map((g) => g.name).join("、") : "还没有游戏记录",
  };
}

/** 这个模块到底有没有内容（「其他模块」面板要不要露脸就看它） */
export function hasData(id, data) {
  if (id === "media") return rows(data, "contents").length > 0;
  if (id === "dev") return rows(data, "projects").length > 0 || rows(data, "issues").length > 0;
  if (id === "study") return rows(data, "subjects").length > 0 || rows(data, "studies").length > 0;

  if (id === "finance") return rows(data, "finance.transactions").length > 0;

}
