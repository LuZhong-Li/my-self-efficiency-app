# 重复任务 与 子任务 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给「今日计划」的待办加两件事：一条待办底下能挂子任务清单（勾选父子联动），以及「每周一、三、五」这种重复规则到日子自动生成当天的待办。

**Architecture:** 纯逻辑全进 `app/web/task-calc.js`（只吃数据、吐结果，能 `node` 直接断言）；重复任务那套在 store 上的胶水单独开 `app/web/repeat.js`（骨架照 `goals.js` 的 `syncGoalTasks`）；界面上「子任务」用一枚共用胶囊零件（`ui.js` 的 `subtaskBadge`）+ 两个共用事件助手（`task-actions.js`），三处列表（今日计划 / 首页 / 项目详情）各只加两行；表单那边 `item-form.js` 加两种控件（`subtasks` 走隐藏 input 里的 JSON、`rule` 是人话规则 + 实时预览），弹窗接线在 `item-dialog.js`。

**Tech Stack:** 原生 HTML/CSS/ES 模块（无框架、无构建、零外链）；Python 3 标准库小服务；测试用 Node 22+ 内置 `fetch` / `WebSocket` 直连 CDP 驱动无头 Edge，不装 puppeteer。

**Spec:** `docs/superpowers/specs/2026-10-14-重复任务与子任务-design.md`

```js
/* ---------------- 子任务（2026-10-14 加） ----------------
   一条待办底下挂几件小事：tasks 里多一个 subtasks 数组，每条 { id, text, done }。
   只有一层（子任务不能再挂子任务），一条最多 30 条（上限在这里定义一份）。
   进度不落盘 —— 2/5 每次现算（和「今日进度不另存」一个哲学）。 */

export const SUBTASK_LIMIT = 30;

/** 这条待办的子任务清单。缺字段 / 写得不是数组 / 老数据，一律当空的 —— 页面不用到处判空。 */
export function subTasksOf(task) {
  if (!task || typeof task !== "object" || !Array.isArray(task.subtasks)) return [];
  return task.subtasks.filter((s) => s && typeof s === "object");
}

/** 清单的完成情况：{ done, total, percent }。没清单时长 0、百分比 0（不是 NaN）。 */
export function subtaskProgress(task) {
  const list = subTasksOf(task);
  const done = list.filter((s) => s.done === true).length;
  const total = list.length;
  return { done, total, percent: total ? Math.round((done * 100) / total) : 0 };
}

/** 父任务勾上 / 取消时，把清单整体带成一样的状态。
 *  返回一份**新的**清单，不改传进来的那条（勾选联动要能当纯函数测）。 */
export function setSubtasksDone(task, done) {
  return subTasksOf(task).map((s) => ({ id: s.id, text: s.text, done: Boolean(done) }));
}

/** 子任务的文字拼成一段（搜索池要用：搜「改侧栏」能带出父任务）。 */
export function subtaskTextOf(task) {
  return subTasksOf(task).map((s) => String(s.text || "")).filter(Boolean).join(" ");
}
```

在文件末尾追加：

```js
/* ---------------- 重复任务（2026-10-14 加） ----------------
   一条规则 = tasks 里 repeat 有内容、且不占某一天（date 空）的那条记录；
   到日子了给它生成一条当天的实例（带 genKey / repeatId）。
   规则怎么解析、哪天算数，直接用 goal-calc.js 那套现成的（parseRule / clauseMatches），
   和模块目标的「自动任务规则」一句话也不差；这里只管「今天该补哪几条」。 */

/** 这条是不是规则：repeat 有内容、没归档、且不占某一天。
 *  生成出来的实例有日期、身上也没有 repeat，所以不会被误认成规则。 */
export function isRepeatRule(row) {
  if (!row || typeof row !== "object") return false;
  if (!String(row.repeat || "").trim()) return false;
  if (taskArchived(row)) return false;
  return !row.date;
}

/** 所有生效中的规则（页面上那张卡片、对表都用这一份） */
export function repeatRulesOf(tasks) {
  return (tasks || []).filter((t) => isRepeatRule(t));
}

/** 这一天是不是这条规则的日子。repeatUntil 之后一律不算（「重复到哪天」）。 */
export function repeatDueOn(rule, date) {
  if (!rule || !String(rule.repeat || "").trim()) return false;
  if (rule.repeatUntil && date > rule.repeatUntil) return false;
  return parseRule(rule.repeat, {}).some((clause) => clauseMatches(clause, date, {}));
}

/** 防重键：同一条规则、同一天只生成一条 */
export function genKeyOf(rule, date) {
  return "repeat:" + rule.id + ":" + date;
}

/** 日期加减（本地时区，不走 UTC；和 goal-calc.js 的日期小工具一个口径） */
export function addDays(date, n) {
  const [y, m, d] = String(date).split("-").map(Number);
  const dt = new Date(y, m - 1, d + n);
  const p = (x) => String(x).padStart(2, "0");
  return dt.getFullYear() + "-" + p(dt.getMonth() + 1) + "-" + p(dt.getDate());
}

/** 卡片上那行「下次：10-16」：从明天往后找最近一天，最多找 400 天（够跨年了）；
 *  过了 repeatUntil 就是空串，卡片上写「已到期，不再生成」。 */
export function nextRepeatDay(rule, today) {
  if (!rule || !String(rule.repeat || "").trim()) return "";
  const clauses = parseRule(rule.repeat, {});
  if (!clauses.length) return "";
  let date = addDays(today, 1);
  for (let i = 0; i < 400; i += 1) {
    if (rule.repeatUntil && date > rule.repeatUntil) return "";
    if (clauses.some((clause) => clauseMatches(clause, date, {}))) return date;
    date = addDays(date, 1);
  }
  return "";
}

/** 从规则抄一条实例（今天要做的那条）。id / createdAt 留给上屏那边补。 */
function instanceOfRule(rule, today, key) {
  return {
    id: "",
    date: today,
    time: rule.time || "",
    text: rule.text || "",
    done: false,
    doneAt: null,
    category: rule.category || "",
    priority: rule.priority || "",
    note: rule.note || "",
    tags: Array.isArray(rule.tags) ? rule.tags.slice() : [],
    // 清单抄一份过去，勾选从零开始（今天的勾不带到明天那条）。id 由调用方补。
    subtasks: subTasksOf(rule).map((s) => ({ id: "", text: String(s.text || ""), done: false })),
    belong: "plan",
    genKey: key,
    repeatId: rule.id,
    imagePaths: [],          // 故意不继承图片：共用路径的话删今天是会误删规则那张
    createdAt: "",
  };
}

/**
 * 对一遍表：给「今天」挑出该补的重复任务。
 *
 * 两道闸和 planGoalTasks 一个形状：
 *   1. genKey（规则 id + 日期）—— 同一条规则同一天只生成一次；
 *   2. rule.lastRun —— 今天已经对过表就不再补，所以你自己删掉的那条不会被加回来。
 *
 * 返回 { newTasks, markRun }：newTasks 交给调用方补 id / 时间再 push；
 * markRun 那些规则要把 lastRun 记成今天。纯函数，不写盘、不改入参。
 */
export function planRepeatTasks(rules, tasks, today) {
  const existing = new Set((tasks || []).map((t) => t && t.genKey).filter(Boolean));
  const newTasks = [];
  const markRun = [];
  for (const rule of rules || []) {
    if (!isRepeatRule(rule)) continue;
    if (!repeatDueOn(rule, today)) continue;      // 今天不是它的日子
    if (rule.lastRun === today) continue;         // 今天已经对过表了
    const key = genKeyOf(rule, today);
    if (!existing.has(key)) {
      existing.add(key);
      newTasks.push(instanceOfRule(rule, today, key));
    }
    markRun.push(rule.id);
  }
  return { newTasks, markRun };
}
```

```js
/**
 * 表单里那条隐藏 input 的 JSON → 干净的数组。读的时候一律经过这里：
 * 坏 JSON 当空的、两头空白掐掉、空条目扔掉、done 转成布尔。
 * （服务端那边也会补形状，见 app/服务.py 的 normalize_data —— 两边往同一个形状收。）
 */
export function parseSubtaskJson(raw) {
  let list;
  try {
    list = JSON.parse(String(raw == null ? "" : raw) || "[]");
  } catch {
    return [];
  }
  if (!Array.isArray(list)) return [];
  return list
    .map((s) => ({
      id: String((s && s.id) || ""),
      text: String((s && s.text) || "").trim(),
      done: Boolean(s && s.done),
    }))
    .filter((s) => s.text);
}

/** 编回那条隐藏 input 的值（编辑回填、新增默认值都走它，免得两边各拼一遍） */
function encodeSubtasks(list) {
  return JSON.stringify(
    (Array.isArray(list) ? list : []).map((s) => ({
      id: String((s && s.id) || ""),
      text: String((s && s.text) || ""),
      done: Boolean(s && s.done),
    }))
  );
}
```

```js
/**
 * 子任务清单那一小块：加一条、删一条、勾一条，全在这儿。
 *
 * 值和别处一样还是从表单走（kind: "subtasks" 读写的是一条隐藏 input 里的 JSON），
 * 所以这里只管把界面上的清单和那条隐藏 input 对齐 —— 校验、写回记录一个字都不重复。
 */
function bindSubtasks(el, spec) {
  for (const field of spec.fields.filter((f) => f.kind === "subtasks")) {
    const host = el.querySelector('[data-subtasks="' + field.name + '"]');
    if (!host) continue;
    const hidden = host.querySelector("#item-" + field.name);
    const listEl = host.querySelector(".sub-list");
    const input = host.querySelector(".sub-input");
    const hint = host.querySelector("[data-sub-hint]");
    if (!hidden || !listEl || !input || !hint) continue;

    const read = () => parseSubtaskJson(hidden.value);
    const draw = (list) => {
      listEl.innerHTML = list.length
        ? list
            .map(
              (s, i) =>
                '<li class="subtask' + (s.done ? " done" : "") + '" data-i="' + i + '">' +
                  '<label class="check" title="这条做完了没">' +
                  '<input type="checkbox" data-sub-check' + (s.done ? " checked" : "") + '></label>' +
                  '<span class="sub-text">' + esc(s.text) + '</span>' +
                  '<button type="button" class="link danger" data-sub-del>删除</button>' +
                '</li>'
            )
            .join("")
        : '<li class="sub-empty">还没加子任务</li>';
      hint.textContent = list.length
        ? list.filter((s) => s.done).length + " / " + list.length + " 条已完成"
        : "最多 " + SUBTASK_LIMIT + " 条";
    };
    const write = (list) => {
      hidden.value = JSON.stringify(list);
      draw(list);
    };
    const addOne = () => {
      const text = String(input.value || "").trim();
      if (!text) return;
      const list = read();
      if (list.length >= SUBTASK_LIMIT) {
        hint.textContent = "最多 " + SUBTASK_LIMIT + " 条，加不下了";
        return;
      }
      list.push({ id: uid(), text, done: false });   // id 在这儿发：列表上那个勾选框靠它认人
      input.value = "";
      write(list);
      input.focus();
    };

    host.addEventListener("click", (e) => {
      const del = e.target.closest("[data-sub-del]");
      if (del) {
        const li = del.closest("[data-i]");
        const list = read();
        if (li) list.splice(Number(li.dataset.i), 1);
        write(list);
        return;
      }
      if (e.target.closest("[data-sub-add]")) addOne();
    });
    host.addEventListener("change", (e) => {
      const box = e.target.closest("[data-sub-check]");
      if (!box) return;
      const li = box.closest("[data-i]");
      const list = read();
      const item = li ? list[Number(li.dataset.i)] : null;
      if (item) item.done = box.checked;
      write(list);
    });
    // 回车在这儿是「加下一条」，所以得拦下来别冒到弹窗那层（那边回车 = 保存）；
    // 和备注那种多行输入一个规矩：正在加清单的时候回车不做保存。
    input.addEventListener("keydown", (e) => {
      if (e.key !== "Enter") return;
      e.preventDefault();
      e.stopPropagation();
      addOne();
    });
    draw(read());   // 编辑老记录时进来就把已有的清单画出来
  }
}
```

```js
/**
```

```js
/** 只写 done / doneAt 这一格（子任务联动和别的地方都走它） */
function writeDone(task, done) {
  task.done = Boolean(done);
  task.doneAt = task.done ? new Date().toISOString() : null;
  return task;
}

/**
 * 勾 / 取消一条待办：顺带把它的子任务清单整体带成一样的状态（父 → 子）。
 * 「勾上父任务 → 清单全勾；取消父任务 → 全部取消」就发生在这一处，
 * 所以今日计划、首页、项目详情三处点复选框的表现天然一样。
 * 只改内存，不落盘不重画（谁调用谁负责）。
 */
export function markTaskDone(task, done) {
  writeDone(task, done);
  if (subTasksOf(task).length) task.subtasks = setSubtasksDone(task, done);
  return task;
}

/**
 * 勾 / 取消**一条子任务**（列表里就地展开那份清单上的复选框）。
 *
 * 子 → 父：清单全勾上就把父任务一起勾上；只要有一条没勾（刚取消的这条也算），
 * 父任务就跟着取消。这里用 writeDone 而不是 markTaskDone —— 走后者会把父任务的状态
 * 反过来铺给整份清单（取消一条会把别的子任务也一起取消）。
 */
export function setSubtaskDone(taskId, subId, done) {
  const task = findTask(taskId);
  if (!task) return null;
  const sub = subTasksOf(task).find((s) => s.id === subId);
  if (!sub) return null;
  sub.done = Boolean(done);
  const p = subtaskProgress(task);
  writeDone(task, p.total > 0 && p.done === p.total);
  touch(true);
  return task;
}

/** 列表里那个子任务复选框：认出来就处理掉、返回 true（页面那边的 change 就别管了） */
export function handleSubtaskChange(e) {
  const box = e.target.closest('[data-act="sub"]');
  if (!box) return false;
  const li = box.closest("[data-id]");
  if (li) setSubtaskDone(li.dataset.id, box.dataset.sub, box.checked);
  return true;
}

/** 行上那枚「2/5」：点一下就地展开 / 收起（只动这一层 DOM，不改数据、不落盘） */
export function handleSubtaskClick(e) {
  const btn = e.target.closest('[data-act="sub-open"]');
  if (!btn) return false;
  const li = btn.closest("[data-id]");
  if (li) li.classList.toggle("sub-open");
  return true;
}
```

```js
/* 一句人话里有没有「哪几天」：和 goal-calc.js 里那套判据一个口径
 * （周几 / 每天 / 每月几号）。这里再写一份，是为了在**保存之前**就拦住
 * 「写了一句没日子的话」—— 不然它会被当成「每天」，天天生成一条。 */
const HAS_TIME_TOKEN =
  /(?:周|星期|礼拜)\s*[一二三四五六日天1-7]|每\s*(?:天|日)|天天|每\s*(?:个)?\s*月/;

/** 重复规则那句话有没有毛病：返回空串表示没问题，否则是一句给人看的话。
 *  「空着」交给 required 报，这里只管「写了但没写出哪几天」。 */
export function repeatRuleError(text) {
  const t = String(text == null ? "" : text).trim();
  if (!t) return "";
  if (!HAS_TIME_TOKEN.test(t)) {
    return "这句话里没写出哪几天，比如：每周一、三、五 / 每月 1 号";
  }
  return "";
}
```

```js
export function syncRepeatTasks(today = todayStr()) {
  if (!store.data) return 0;
  const tasks = table("tasks");
  const rules = tasks.filter(isRepeatRule);
  const { newTasks, markRun } = planRepeatTasks(rules, tasks, today);
  if (!newTasks.length && !markRun.length) return 0;
  for (const row of newTasks) {

    row.createdAt = new Date().toISOString();

  }

/** 页面的事件里先叫它一声：归它管的返回 true（调用方就别往下处理了） */
export function repeatAction(e) {
  const btn = e.target.closest("[data-act]");
  if (!btn) return false;
  const act = btn.dataset.act;
```
