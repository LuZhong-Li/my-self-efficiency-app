# 自媒体「素材库」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自媒体页多一个「素材」子页：脚本 / 封面 / 参考链接收得进来（图片 + 链接两种，
每条带一句说明），**能勾到作品上**；作品行上一眼看得出用了几个素材；
删素材时引用跟着摘掉，不留指向不存在素材的 id。

**Architecture:** 新增顶层表 `mediaAssets`；关联存在**作品那一侧**
（`contents[].assetIds`），素材页那句「用在 N 条作品上」由作品侧现算。
图片走现成的附件组件、存新目录 `attachments/media_asset/`；子页照记账
「账目记录 / 债务欠款」那对子 Tab 的做法（`#media/assets`）。

**Tech Stack:** 原生 HTML + CSS + ES 模块（无框架、无构建、零外链）；Python 标准库小服务；
测试用 Node（纯逻辑）+ Python（`tests/自检.py`）+ 无头 Edge 的 CDP 回归。

**Spec:** `docs/superpowers/specs/2026-10-14-自媒体素材库-design.md`（动手前先读一遍；
第 1 节那个「读法 A / B」已经拍板走 A）

## Global Constraints

- **零外链**：界面文件里不能出现任何 `http(s)://` 链接；**也不联网**（不做「粘链接自动抓标题」）。
- **不装依赖**：Node 只用来跑 `tests\*.test.mjs`（直接 `node 文件名`）。
- **素材只收两种**：`image`（走附件组件）与 `link`（一段 URL 文本）；不收别的文件。
- **读素材一律走 `normalizeAsset()` / `assetsOf()`**，别直接读 `data.mediaAssets`。
- **引用只在作品侧**：`contents[].assetIds`；删素材必须过 `unlinkAsset()` 摘干净。
- **颜色只用 CSS 变量**；四套皮肤 × 深浅两色都不能破相。
- **事件不挂公共 `#view`**：一律 `bindFresh(root, {...})`；弹窗内部按钮走弹窗自己的 click。
- **增删改走 `touch(true)` 立刻落盘**；删除一律 `moveToTrash(表名, 行, 显示文字)`。
- **注释与提交信息用中文**，说清「为什么」。
- 每个任务结束：本任务对应的 `node tests\*.test.mjs` 与 `python tests\自检.py` 都要过；
  碰了页面的任务还要跑 `node tests\自媒体平台.test.mjs`、`node tests\自媒体快照.test.mjs`、
  `node tests\自媒体补录.test.mjs`（都在自媒体页上，是现成的冒烟）。

/* ---------------- 素材库（2026-10-14 加的） ----------------
   自媒体要用的东西（脚本、封面、参考链接）收进一张 mediaAssets 表；
   「这条作品用了哪几份」存在作品那一侧（contents[].assetIds）——
   日常动作是「做这条作品 → 挑素材」，作品是主动方；素材页那句「用在 N 条作品上」
   由作品侧现算，不会出现第二份真相。删素材时记得摘引用（unlinkAsset）。 */

/** 素材就两种：图片（走附件组件）/ 链接（一段 URL 文本） */
export const ASSET_KINDS = ["image", "link"];

/** 一条素材读出来规整：类型只认 image / link、标题与说明去空白、两种字段不混着留 */
export function normalizeAsset(row) {
  const src = row && typeof row === "object" ? row : {};
  const text = (v) => String(v == null ? "" : v).trim();
  const kind = src.kind === "link" ? "link" : "image";
  return {
    id: text(src.id),
    title: text(src.title),
    kind,
    path: kind === "image" ? text(src.path) : "",
    url: kind === "link" ? text(src.url) : "",
    note: text(src.note),
    createdAt: text(src.createdAt),
  };
}

/** 素材列表（老数据没这个键就是空的，手改坏了也当空；三样全空的残渣丢掉） */
export function assetsOf(data) {
  const list = data && Array.isArray(data.mediaAssets) ? data.mediaAssets : [];
  return list
    .map(normalizeAsset)
    .filter((a) => a.title || a.path || a.url);
}

/** 每份素材被几条作品用着：{ [assetId]: 条数 }（同一条里写两遍只算一条） */
export function assetUsage(assets, contents) {
  const used = new Map();
  for (const c of contents || []) {
    if (!c || !Array.isArray(c.assetIds)) continue;
    for (const id of new Set(c.assetIds.map((x) => String(x == null ? "" : x).trim()).filter(Boolean))) {
      used.set(id, (used.get(id) || 0) + 1);
    }
  }
  const out = {};
  for (const a of assetsOf({ mediaAssets: assets })) out[a.id] = used.get(a.id) || 0;
  return out;
}

/** 这条作品用到的素材（按素材库的顺序给回来；认不出的 id 跳过，不硬塞空壳） */
export function assetsOfContent(content, assets) {
  const raw = content && Array.isArray(content.assetIds) ? content.assetIds : [];
  const ids = new Set(raw.map((x) => String(x == null ? "" : x).trim()).filter(Boolean));
  return assetsOf({ mediaAssets: assets }).filter((a) => ids.has(a.id));
}

/** 删素材时把引用从各作品摘掉（返回新数组，不改传进来的；别的引用一个不动） */
export function unlinkAsset(contents, assetId) {
  const id = String(assetId == null ? "" : assetId).trim();
  return (contents || []).map((c) => {
    if (!c || !Array.isArray(c.assetIds)) return c;
    if (!c.assetIds.some((x) => String(x == null ? "" : x).trim() === id)) return c;
    return {
      ...c,
      assetIds: c.assetIds.filter((x) => String(x == null ? "" : x).trim() !== id),
    };
  });
}
```

/** 素材子页：素材一行一条，头上一个「添加素材」 */
function assetsView() {
  const assets = assetsOf(store.data);
  const usage = assetUsage(assets, table("contents"));
  return `
    <section class="card">
      <div class="card-head">
        <h2>${icon("note", 18)}素材</h2>
        <div class="card-tools">
          <span class="hint">${assets.length ? assets.length + " 份" : ""}</span>
          <button class="btn primary small" data-act="asset-new">${icon("plus", 14)}添加素材</button>
        </div>
      </div>
      ${
        assets.length
          ? `<ul class="items">${assets.map((a) => assetRow(a, usage[a.id] || 0)).join("")}</ul>`
          : emptyState("还没有素材", "把脚本、封面、参考链接收进来，做作品的时候直接挑。", "", "note")
      }
    </section>`;
}

function assetRow(a, used) {
  const thumb =
    a.kind === "image"
      ? `<span class="asset-thumb">${a.path ? `<img src="/${esc(a.path)}" alt="">` : "🖼"}</span>`
      : `<span class="asset-thumb link">🔗</span>`;
  const body =
    a.kind === "link"
      ? `<a class="link" href="${esc(a.url)}" target="_blank" rel="noreferrer">${esc(a.url)}</a>`
      : "";
  return `
    <li class="item asset-row" data-id="${esc(a.id)}">
      ${thumb}
      <span class="asset-main">
        <span class="i-title">${esc(a.title)}</span>
        ${body}
        ${a.note ? `<span class="i-note">${esc(a.note)}</span>` : ""}
      </span>
      <span class="i-meta">${used ? `用在 ${used} 条作品上` : "还没被用过"}</span>
      <span class="i-actions">
        <button class="link" data-act="asset-edit">编辑</button>
        <button class="link danger" data-act="asset-del">删除</button>
      </span>
    </li>`;
}

/** 添加 / 编辑素材。类型二选一：图片（走附件组件）/ 链接（一段 URL） */
function openAssetDialog(id, options = {}) {
  const a = id ? assetsOf(store.data).find((x) => x.id === id) : null;
  let kind = a ? a.kind : "image";
  const attach = createAttach({ module: "media_asset", paths: a && a.path ? [a.path] : [] });
  const { el, close } = openDialog({
    title: a ? "编辑素材" : "添加素材",
    bodyHtml: `
      <label class="fin-label">类型</label>
      <div class="fin-tabs">
        <button type="button" class="fin-tab${kind === "image" ? " active" : ""}"
          data-act="asset-kind" data-kind="image">图片</button>
        <button type="button" class="fin-tab${kind === "link" ? " active" : ""}"
          data-act="asset-kind" data-kind="link">链接</button>
      </div>
      <label class="fin-label" for="asset-title">标题 *</label>
      <input id="asset-title" maxlength="60" placeholder="比如：封面 / 脚本 / 参考视频"
        value="${esc(a ? a.title : "")}">
      ${
        kind === "image"
          ? `<p class="fin-help">一张素材一张图；脚本截图、竖版封面分开建两份就行。</p>`
          : `<label class="fin-label" for="asset-url">链接 *</label>
             <input id="asset-url" maxlength="300" placeholder="https://…"
               value="${esc(a ? a.url : "")}">`
      }
      <label class="fin-label" for="asset-note">说明</label>
      <input id="asset-note" maxlength="200" placeholder="给谁看的、哪里找的（可不填）"
        value="${esc(a ? a.note : "")}">
      <p class="fin-err" id="asset-err" hidden></p>
      ${kind === "image" ? `<div class="attach-host" id="asset-attach"></div>` : ""}`,
    buttons: [
      ...(a ? [{ id: "delete", label: "删除", kind: "danger" }] : []),
      { id: "cancel", label: "取消" },
      { id: "save", label: "保存", kind: "primary" },
    ],
    onClose: () => disposeAttach(attach),
    onAction(act, dlg) {
      const fail = (msg) => {
        const box = dlg.querySelector("#asset-err");
        box.textContent = msg;
        box.hidden = false;
        return false;          // 弹窗留着让人改
      };
      if (act === "cancel") return true;
      if (act === "delete") {
        (async () => {
          const used = assetUsage(assetsOf(store.data), table("contents"))[a.id] || 0;
          const ok = await askConfirm({
            title: `删除素材「${a.title}」？`,
            message: used
              ? `有 ${used} 条作品在用，删掉之后它们的素材里也会少这一份（作品本身不动）。`
              : "还没有作品用它。放进回收站，误删可找回。",
            confirmLabel: "删除",
            danger: true,
          });
          if (!ok) return;
          store.data.contents = unlinkAsset(table("contents"), a.id);   // 先摘引用
          moveToTrash("mediaAssets", a, a.title);
          touch(true);
          dlg.close();
          toast("已移入回收站");
          if (options.onSaved) options.onSaved();
        })();
        return false;
      }
      if (act !== "save") return false;
      (async () => {
        const title = dlg.querySelector("#asset-title").value.trim();
        if (!title) return fail("标题不能是空的");
        const note = dlg.querySelector("#asset-note").value.trim();
        let path = "";
        let url = "";
        if (kind === "image") {
          let uploaded = [];
          try {
            uploaded = await uploadPending(attach);   // 先落图再动 JSON（和记账一个顺序）
          } catch (err) {
            return fail("图片没存下：" + err.message);
          }
          commitUploads(attach, uploaded);
          path = attach.paths[0] || "";
          if (!path) return fail("先选一张图（或者粘贴一张）");
        } else {
          url = dlg.querySelector("#asset-url").value.trim();
          if (!/^https?:\/\//i.test(url)) return fail("链接要以 http 开头");
        }
        if (a) Object.assign(a, { title, kind, path, url, note });
        else table("mediaAssets").push({ id: uid(), title, kind, path, url, note, createdAt: nowText() });
        touch(true);
        dlg.close();
        toast(a ? "素材已更新" : `已添加「${title}」`);
        if (options.onSaved) options.onSaved();
      })();
      return false;
    },
  });
  if (kind === "image") mountAttach(el.querySelector("#asset-attach"), attach);
  // 类型切换：把现在填的值带上、重画那段表单、重新 mountAttach（和记账切支出/收入一个做法）
  el.addEventListener("click", (e) => {
    const btn = e.target.closest('[data-act="asset-kind"]');
    if (!btn) return;
    const keep = {
      title: el.querySelector("#asset-title").value,
      note: el.querySelector("#asset-note").value,
    };
    kind = btn.dataset.kind;
    el.querySelector(".dlg-form").innerHTML = assetFormHtml(kind, keep);
    if (kind === "image") mountAttach(el.querySelector("#asset-attach"), attach);
  });
  return el;
}
```

（上面那段表单 HTML 抽成 `assetFormHtml(kind, values)` 一个小函数，
`openDialog` 里初次渲染与切换类型时都调它 —— 一处定义，两处用。）

规矩：

- **标题**必填（去空白后不能为空）；
- **图片**：`kind === "image"` 时至少要有一张图（附件区里那几张的第一张作为
  `path`，其余的不另存 —— 一份素材一张图，脚本截图就再建一份）；
- **链接**：`kind === "link"` 时必填、要以 `http://` 或 `https://` 开头，
  不然给「链接要 http 开头」；
- 说明选填；保存走 `touch(true)`；新素材 `id: uid()`；
- **删除**（编辑时才有）：先算 `assetUsage(...)`，确认框里写明
  「有 N 条作品在用，删掉之后它们的素材里也会少这一份」；确认后
  `unlinkAsset(table("contents"), id)` 摘引用（**把返回的新数组写回
  `store.data.contents`**）、`moveToTrash("mediaAssets", a, a.title)`、`touch(true)`。
