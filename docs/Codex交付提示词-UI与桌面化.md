## 3. 任务目标（三条主线）

### 主线一：桌面化 —— 自有窗口，不进浏览器
- 双击 `启动.cmd`：不出现黑色控制台窗口；
- 出现标题为「小李」的独立桌面窗口（pywebview + WebView2 渲染现有页面），任务栏独立图标；
- 窗口关闭 = 程序退出，端口释放、无残留进程；
- **回退机制（硬性）**：pywebview 缺失或 import 失败时，自动回退到现在的浏览器模式，双击依然能用。

### 主线二：消灭黑窗口
- 服务用 `pythonw.exe`（无控制台）启动；`print` 输出重定向到日志文件；
- 新增 `启动-调试.cmd`（`python.exe` 带控制台）供排错。

### 主线三：UI 设计感升级（纯 CSS 增量，不破坏结构）
- 背景升级为柔和渐变；顶栏/侧栏做半透明毛玻璃质感（backdrop-filter + 高光描边）；
- 卡片双档阴影 + hover 抬升反馈；
- 11 个模块各配主题色（侧栏图标、卡片强调条），明暗两套都可辨识；
- 排版层级、统计数字等宽（tabular-nums）；
- 轻动效（页面淡入、弹窗缩放进场、按钮按压），**尊重 `prefers-reduced-motion: reduce`**；
- 空状态内联 SVG 配图、统一聚焦环、选中态、图标统一线性风格。

## 5. 实施步骤（按计划文档执行，此处为执行要点）

### M1 桌面外壳（改 2 个文件 + 新增 1 个脚本 + 1 个测试）

**`app\服务.py`**：
1. 新增 `--desktop` 参数（或环境变量 `XIAOLI_DESKTOP=1`）触发桌面模式；
2. 新增 `desktop_available()`：`try: import webview; return True`，except 返回 False；
3. 新增 `run_desktop(httpd, port)`：
   - `threading.Thread(target=httpd.serve_forever, daemon=True).start()`
   - `webview.create_window("小李", "http://127.0.0.1:{port}/", width=1280, height=860, min_size=(960, 640), icon=根目录小李.ico 的绝对路径（存在才传）)`
   - `webview.start()` 返回后 `httpd.server_close()`，进程自然退出；
4. `main()` 分支：`--desktop` 且 pywebview 可用 → 桌面路径；否则 → 现有浏览器模式（`threading.Timer(0.15, open_browser)` 原样保留）；
5. 日志重定向：检测到 stdout 无效（pythonw 下 `sys.stdout is None`）时，把 print 输出追加到 `日志\console.log`（在数据目录内，复用现有 `log_line` 的目录定位逻辑；若 `日志\` 在数据集目录下，则按当前数据集目录定位，与数据集功能兼容）。

**`启动.cmd`**：
1. 现有 Python 探测逻辑**原样保留**；
2. 探测到 `%PY%` 后，优先用同目录的 `pythonw.exe` 跑 `"app\服务.py" --desktop`；没有 pythonw 时回退 `python.exe`；
3. 找不到可用 Python 时的报错提示逻辑保留。

**新增 `启动-调试.cmd`**：用 `python.exe` 跑 `app\服务.py`（不带 `--desktop`，带控制台、浏览器模式），注释说明用途（排错看日志）。

**新增 `tests\桌面回退.test.mjs`**（复用现有测试脚手架：临时数据目录 + 无头 Edge CDP）：
- ① 断言 `--no-browser` 下服务照常可被无头浏览器访问（回归既有行为）；
- ② 若 `desktop_available`/pythonw 探测逻辑抽成了可测纯函数，则补单测；
- ③ 测试说明注明：pywebview 原生窗口本身不进 CDP 测试，靠人工验收 + 回退测试兜底。

**M1 人工验收（交付前自己跑一遍）**：双击 `启动.cmd` 无黑窗、出现小李窗口；改一条数据 → 关窗 → 重开数据在；关窗后 `netstat -ano | findstr :8765` 无残留；临时卸载 pywebview 后双击回退浏览器模式。

### M2 视觉升级第一波（style.css 增量，与 M1 并行）

1. `:root` 与 `html[data-theme="dark"]` 各追加一组设计令牌变量（背景渐变、玻璃底色/模糊/高光描边、阴影第二档、动效时长与缓动、11 个模块主题色 `--m-home` … `--m-set`；深色块覆盖更亮版本保证对比度）；
2. 增量规则：body 渐变背景、.topbar/.sidebar 玻璃质感（backdrop-filter + 半透明 + 高光边）、卡片 hover 抬升、弹窗玻璃背景 + 进出场动效、按钮 `:active` 微缩、侧栏模块图标与模块卡片使用 `--m-*` 主题色、统计数字 `font-variant-numeric: tabular-nums`；
3. 动效全部 `@media (prefers-reduced-motion: reduce)` 关闭。

空状态（内联 SVG + 一句话 + 引导按钮，新建公共函数）、统一 `:focus-visible` 聚焦环、选中态统一、`icons.js` 图标走查补齐（同一线性风格、不改图标名）、弹窗/抽屉/搜索面板动效统一、11 个模块明暗各 1 张走查截图并修复问题。
