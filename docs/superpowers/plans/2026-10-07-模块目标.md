# 模块目标 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 健身 / 学习工作 / 饮食计划三个模块各加一条模块级目标：能设周期和起止、
能按一句人话规则自动往「今日计划」生成待办、能看进度；数据存在 `moduleGoals` 里，
和待办、笔记分开。

**Architecture:** 新增 `goal-calc.js`（纯逻辑：目标形状 / 规则解析 / 自动生成 / 进度，
`node` 直接可测）和 `goals.js`（接 store：卡片、按钮、自动生成、摘要）。
弹窗复用 `openItemDialog`，往 `item-form.js` 加一个 `moduleGoal` 类型；
`item-dialog.js` 只加四个小口子（没有图片区就不装配件、checkbox 读数、
`persist` 落盘、自定义删除计划）。服务端只加数据键与迁移。

**Tech Stack:** 原生 HTML + CSS + ES 模块（无框架、无构建、零外链）；
弹窗用现成的 `openDialog`；Python 标准库小服务；Node 跑纯逻辑单测。

**Spec:** `docs/superpowers/specs/2026-10-07-模块目标-design.md`

## Global Constraints

- **零外链**：`.html` / `.css` / `.js` 里不能出现 `http(s)://`（`tests/自检.py` 会扫）。
- **不装依赖**：Python 标准库 + 本机 Node v24，不建 `node_modules`。
- **事件不挂公共 `#view`**：一律 `bindFresh(root, { click, submit, change, input })`。
- **只做加法**：老记录字段一个都不改；项目里的待办（`belong: "dev:<id>"`）行为不变。
- **只读来源标记**：自动生成的待办上 `sourceModule / goalId / genKey` 不进表单，
  改正文不会把它们冲掉。
- **删除只在目标层面**：删目标不删已生成的待办，也不进回收站。
- **注释和提交信息用中文**，说清「为什么」。
- 每个任务结束时：`python tests\自检.py` 全过、`node tests\*.test.mjs` 全过。

### Task 1: 纯逻辑 `goal-calc.js`（先写测试）

**Files:** Create `app/web/goal-calc.js`、`tests/目标计算.test.mjs`

**Interfaces（后面所有任务只用这些名字）:**

```js
GOAL_MODULES / GOAL_CYCLES / WEEKDAY_NAMES
goalModuleOf(id) / sourceLabelOf(moduleId) / categoryOf(moduleId)
weekdayOf(date) / dayOfMonth(date) / weekStartOf(today) / weekRangeOf(today)
normalizeGoal(raw, moduleId) / rawGoals(data, moduleId) / allGoals(data) / ensureBucket(data, moduleId)
parseRule(rule, goal) -> [{ weekdays, monthlyDays, everyDay, text }]
clauseMatches(clause, date, goal) / previewDays(clause, goal)
rulePreview(rule, goal) / ruleSummary(rule, goal)
isActiveOn(goal, date) / tasksForDate(goal, date) -> [{ key, goalId, moduleId, text }]
planGoalTasks(goals, tasks, date) -> { newTasks, markRun }
progressOf(goal, tasks, today) -> { total, done, percent, weekTotal, weekDone, weekDays, unit, allText }
cycleText(goal)
```

**Steps:**

- [x] 1. 写 `tests/目标计算.test.mjs`（骨架照 `tests/记账计算.test.mjs`）。
- [x] 2. 写 `app/web/goal-calc.js`。
- [x] 3. `node tests\目标计算.test.mjs` → **140 项**全过。

**断言要点**：三个模块 / 四档周期；`normalizeGoal` 补齐字段且顺序固定；
`moduleGoals` 写成数组或单对象都能读；星期串的六种写法（`周一` / `星期一` /
`礼拜天` / `周1` / `每周一三五` / `周一和周三`）以及「三十分钟里的三不算星期」；
`每天` / `每月 N 号`；逗号两边各自带时间词才拆句；`ruleSummary` 的整句预览；
有效期（起止 + 开关）；`tasksForDate` 的五种不生成情形；`planGoalTasks`
的两道防重复闸；`progressOf` 只数自己生成的那几条。

**踩到的两个坑**（都写进断言了）：

1. `每周一三五自动生成【力量训练】待办到今日计划` —— 去掉「自动生成」之后
   「待办到今日计划」会剩下一个「待办到」。改成先整段去掉「到今日计划」，
   再收尾去掉「待办 / 任务 / 提醒」，任务文字才干净。
2. `每周一、三、五力量训练；周二、四有氧` 的第二条预览成「每周二、周四」，
   和第一条的「每周一、周三、周五」不整齐。统一成「每 + 星期列表」，
   预览和生成口径一起对齐。
