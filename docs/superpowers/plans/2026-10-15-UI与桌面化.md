## 3. M1 桌面外壳

### 3.1 `app\服务.py` 改造

1. **新增桌面模式入口**：
   - 参数 `--desktop`（或环境变量 `XIAOLI_DESKTOP=1`）触发；
   - 函数 `desktop_available()`：`try: import webview; return True except: return False`；
   - `main()` 在绑好端口后分叉：
     - 桌面模式 + pywebview 可用 → 桌面窗口路径；
     - 其余 → 浏览器模式（现逻辑 `threading.Timer(0.15, open_browser)` 不变）。
2. **桌面窗口路径**（新增 `run_desktop(httpd, port)`）：
   ```python
   def run_desktop(httpd, port):
       import webview
       threading.Thread(target=httpd.serve_forever, daemon=True).start()
       webview.create_window(APP_NAME, "http://127.0.0.1:%d/" % port,
                             width=1280, height=860, min_size=(960, 640),
                             icon=ICON_PATH if os.path.exists(ICON_PATH) else None)
       webview.start()
       httpd.server_close()
   ```
   - `ICON_PATH` 指向仓库根 `小李.ico`（运行时按 `os.path` 定位，不硬编码）；
   - `webview.start()` 返回（窗口关闭）后 `server_close()` 释放端口，进程自然退出（满足 D-5）。
3. **日志重定向**：`setup_console()` 之后，若检测到 stdout 无效（pythonw 下 `sys.stdout is None`），把 print 输出附加到 `日志\console.log`；现有 `log_line`（数据目录内日志）不动。
4. **既有行为零回归**：`--no-browser`、`--port`、数据集功能、`XIAOLI_DATA_DIR` 全部原样保留；`--desktop` 缺省时不改变任何现有行为。

### 3.2 `启动.cmd` 改造

1. 现有 Python 探测逻辑（多候选逐个试导入）保留不动；
2. 探测到 `%PY%` 后：
   - 优先取同目录 `pythonw.exe`（`%PY%` 的同名目录下）；
   - 用 `pythonw.exe` 跑 `app\服务.py --desktop`；
   - 找不到 pythonw 时回退 `python.exe`（仍有控制台，但能跑）。
3. 新增 `启动-调试.cmd`：用 `python.exe` 跑 `app\服务.py`（不带 --desktop，带控制台，浏览器模式），专供排错看日志。

### 3.3 新增测试

| 测试 | 内容 |
| --- | --- |
| `tests\桌面回退.test.mjs` | ① `desktop_available()` 纯逻辑：pywebview 可 import 判定；② 服务在 `--no-browser` 下照常可被无头 Edge 访问（回归既有行为）；③ pythonw 路径探测逻辑纯函数单测（若抽成可测函数） |

- pywebview 原生窗口本身**不进 CDP 测试**（原生窗口无法用无头浏览器断言），靠人工验收 + 回退机制测试兜底；这条限制写进测试说明。

## 4. M2 视觉升级第一波（与 M1 并行）

### 4.1 设计令牌（style.css 尾部追加 `/* ---- 2026-10-15 设计感升级 ---- */` 区块）

在 `:root` 与 `html[data-theme="dark"]` 各追加一组新变量（只增不改）：

```css
/* 背景 */
--bg-grad: linear-gradient(160deg, #eef2fb 0%, #f5f6f8 55%, #eef0f7 100%);
--bg-grad-dark: radial-gradient(1200px 700px at 20% -10%, #1b2440 0%, #111827 55%, #0d1220 100%);
/* 玻璃（顶栏/侧栏/弹窗） */
--glass-bg: rgba(255,255,255,0.72);
--glass-bg-dark: rgba(23,27,39,0.66);
--glass-blur: 14px;
--glass-line: rgba(255,255,255,0.55);      /* 高光描边 */
--glass-line-dark: rgba(148,163,255,0.10);
/* 阴影第二档（hover/抬升） */
--shadow-2: 0 10px 30px rgba(31,41,55,0.10);
--shadow-2-dark: 0 12px 34px rgba(0,0,0,0.5);
/* 动效 */
--dur-s: 120ms; --dur-m: 180ms; --dur-l: 240ms;
--ease: cubic-bezier(.22,.61,.36,1);
/* 模块主题色（浅色为基准，深色在 dark 块覆盖更亮版本） */
--m-home:#3b66d9; --m-plan:#7c5cf0; --m-media:#e8598e; --m-dev:#e07b39;
--m-study:#2f9e8f; --m-fin:#27ae60; --m-fit:#e0a63b; --m-diet:#6aa84f;
--m-game:#9b59b6; --m-note:#5b8def; --m-set:#7a8699;
```

### 4.2 视觉改造点（全部增量规则 + 注释）

| 位置 | 改动 |
| --- | --- |
| body | `background: var(--bg-grad)`（深色 `--bg-grad-dark`）；加 `min-height:100vh` 保证渐变铺满 |
| .topbar | `background: var(--glass-bg); backdrop-filter: blur(var(--glass-blur));` 底部高光边 `border-bottom:1px solid var(--glass-line)` |
| .sidebar | 同上玻璃质感；给「当前模块选中态」加主题色左侧条（沿用现有选中 class，只加样式） |
| .card / 卡片容器 | 常态阴影升级为双档：默认 `var(--shadow)`，hover `translateY(-2px) + var(--shadow-2)`；`transition: transform var(--dur-s), box-shadow var(--dur-s)` |
| 弹窗 .dlg | `backdrop-filter` 玻璃背景 + 进场动效（scale 0.96→1 + fade，≤180ms；关闭反向）；`prefers-reduced-motion` 下禁用 |
| 按钮 | hover 过渡 + `:active { transform: scale(.98) }` |
| 侧栏模块图标 | 每模块图标用 `--m-*` 主题色（图标底色/描边/文字色） |
| 模块卡片 | 卡片左侧 4px 主题色条（或图标着色），标识所属模块 |
| 统计数字 | `font-variant-numeric: tabular-nums` |

## 7. 风险与回滚

| 风险 | 对策 |
| --- | --- |
| pywebview 启动失败 | D-3 回退浏览器模式；`启动-调试.cmd` 看日志定位 |
| pythonw 下无输出难排错 | print 重定向 `日志\console.log`；调试 cmd 保留控制台 |
| CSS 增量覆盖错乱 | 每步截图对比 + 46 测试兜底；出问题即回退到 git 上一版 style.css（增量块独立，易回滚） |
| 窗口关闭有进程残留 | 验收强制 `netstat` 查端口；`server_close()` 兜底 |
| 同步日常份后异常 | 同步前 git 提交留档；日常份数据目录不动，代码可随时回滚重同步 |
