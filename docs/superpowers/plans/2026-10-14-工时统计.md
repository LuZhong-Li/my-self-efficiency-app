# 工时统计 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 开发工作加一个「工时统计」子页（`#dev/hours`）：记一笔工时（哪天、哪个项目、多久）、跑秒表、看今日 / 本周 / 本月 / 累计、近 6 个月柱状图和按项目的分布。

**Architecture:** 时长换算与计时那八个函数从 `game-calc.js` 搬到新的 `app/web/time-calc.js`（原处转出，别的文件和测试一个字不改）；工时自己的纯逻辑在新文件 `app/web/work-calc.js`；界面是 `dev.js` 里的一个子页（子 Tab 照记账那套）；柱状图与横条复用上一轮的 `chart-calc.js`。

**Tech Stack:** 原生 HTML/CSS/ES 模块（无框架、无构建、零外链）；Python 3 标准库小服务；测试用 Node 22+ 内置 `fetch` / `WebSocket` 直连 CDP 驱动无头 Edge。

**Spec:** `docs/superpowers/specs/2026-10-14-工时统计-design.md`

## Global Constraints

- **零外链**：任何 `.html` / `.css` / `.js` 里不许出现 `http://` 或 `https://` 字面量（`tests\自检.py` 的 `check_no_external()` 会正则扫）。
- **老数据迁移只补不改**：缺了才补默认值，已经有了的一个字节都不动（`app/服务.py` 的 `normalize_data`）。
- **一个任务一个提交**，commit message 用中文、写清「为了什么」；直接提交到 `main`。
- 注释用中文，写「为什么这么写」。
- 每改完一处至少跑：`node tests\<相关>.test.mjs` 和 `& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" tests\自检.py`。
- 测试断言写错就改测试，不改实现。
- **时长只存分钟**（`minutes`）；表单里「数字 + 单位」两格，落盘前拧成分钟，数据里不留影子字段。
- 工时**不给图片区**（省掉一处附件白名单与设置页文案的同步）。
- 本周一律**从周一算起**（和游戏、首页一个口径）。

- [ ] **Step 3: 写最小实现**

新建 `app/web/work-calc.js`：

```js
/* 工时统计的纯逻辑：一条工时长什么样、四档汇总、按月、按项目。
 * 只吃数据、吐结果，不碰 DOM、不碰 store —— `node tests\工时计算.test.mjs` 能一条条断言。
 *
 * 一条工时 = 「哪天在哪个项目上花了多久」（minutes 统一按分钟存）。
 * 口径和游戏、首页那套对齐：本周从周一算起；没填日期的只进「累计」，
 * 不进任何一段时间、也不进按月的图。
 */

import { weekStartOf } from "./goal-calc.js";
import { barRatioOf } from "./chart-calc.js";

const LOOSE_NAME = "没记项目";     // projectId 空的（就是没挑项目）
const GONE_NAME = "（项目已删）";   // projectId 指着一个已经不在 projects 里的 id

function num(value) {
  const n = Number(value);
  return Number.isFinite(n) ? n : 0;
}

function text(value) {
  return String(value == null ? "" : value).trim();
}

/** 项目 id → 显示名：空 id 是「没记项目」，id 找不着是「（项目已删）」。
 *  统计那一块和记录列表都用它，两处的名字才是同一个口径。 */
export function projectLabelOf(projectId, projects) {
  const id = text(projectId);
  if (!id) return LOOSE_NAME;
  const found = (projects || []).find((p) => p && text(p.id) === id);
  return found ? text(found.name) || "（没写名字）" : GONE_NAME;
}

/** 把一条工时补齐成完整形状（老数据、手写数据都认） */
export function normalizeWorkLog(row) {
  const r = row && typeof row === "object" ? row : {};
  return {
    id: text(r.id),
    date: text(r.date),
    projectId: text(r.projectId),
    minutes: Math.max(0, Math.round(num(r.minutes))),
    note: text(r.note),
    // 标签和别处一个规矩：只认数组（清洗与去重是 tag-calc.js 的事，这里不猜、不拆字符串）
    tags: Array.isArray(r.tags) ? r.tags.map((t) => text(t)).filter(Boolean) : [],
    createdAt: text(r.createdAt),
  };
}

/** 今日 / 本周（周一起）/ 本月 / 累计：分钟数 + 条数 + 玩过几天（同一天多条算一天） */
export function workStatsOf(logs, today) {
  const day = text(today);
  const week = weekStartOf(day);
  const month = day.slice(0, 7);
  const out = { todayMin: 0, weekMin: 0, monthMin: 0, allMin: 0, count: 0, days: 0 };
  const seen = new Set();
  for (const raw of logs || []) {
    const row = normalizeWorkLog(raw);
    out.allMin += row.minutes;
    out.count += 1;
    if (!row.date) continue;
    seen.add(row.date);
    if (row.date === day) out.todayMin += row.minutes;
    if (row.date >= week && row.date <= day) out.weekMin += row.minutes;
    if (row.date.slice(0, 7) === month) out.monthMin += row.minutes;
  }
  out.days = seen.size;
  return out;
}

/** 每个月各花了多久（给柱状图）。months 是「2026-10」这种串，顺序照传进来的排。 */
export function monthMinutesOf(logs, months) {
  const list = Array.isArray(months) ? months : [];
  const sums = new Map();
  for (const raw of logs || []) {
    const row = normalizeWorkLog(raw);
    if (!row.date) continue;
    const key = row.date.slice(0, 7);
    sums.set(key, (sums.get(key) || 0) + row.minutes);
  }
  const minutesOf = list.map((m) => Math.max(0, sums.get(text(m)) || 0));
  const max = minutesOf.reduce((best, m) => Math.max(best, m), 0);
  return list.map((month, i) => ({
    month: text(month),
    minutes: minutesOf[i],
    ratio: barRatioOf(minutesOf[i], max),
  }));
}

/**
 * 按项目汇总，按工时降序。项目名从 projects 表里取。
 * 「没记项目」（projectId 空）和「（项目已删）」（id 找不着了）各留一行 ——
 * 数据在，就不该在图里凭空消失。
 */
export function byProjectOf(logs, projects) {
  const buckets = new Map();
  let total = 0;
  for (const raw of logs || []) {
    const row = normalizeWorkLog(raw);
    const key = row.projectId;
    const cur = buckets.get(key) || { projectId: key, minutes: 0, count: 0 };
    cur.minutes += row.minutes;
    cur.count += 1;
    buckets.set(key, cur);
    total += row.minutes;
  }
  const rows = [...buckets.values()].map((b) => ({
    ...b,
    name: projectLabelOf(b.projectId, projects),
  }));
  const max = rows.reduce((best, r) => Math.max(best, r.minutes), 0);
  return rows
    .map((r) => ({
      ...r,
      ratio: barRatioOf(r.minutes, max),
      share: total ? Math.round((r.minutes / total) * 1000) / 1000 : 0,
    }))
    .sort((a, b) => b.minutes - a.minutes || (a.name < b.name ? -1 : 1));
}

/** 分布太长时只画前 top 名，剩下的收成一行「还有 N 个 · 合计多少」 */
export function collapseRows(rows, top = 6) {
  const list = Array.isArray(rows) ? rows : [];
  const n = Math.max(1, Math.floor(num(top) || 1));
  const shown = list.slice(0, n);
  const rest = list.slice(n);
  return {
    shown,
    rest: rest.length,
    restMinutes: rest.reduce((sum, r) => sum + Math.max(0, num(r && r.minutes)), 0),
  };
}
```

```js
/** 秒表照着游戏页那套：记在 sessionStorage 里，切到别的模块再回来还在计 */
function workTimerStartedAt() {
  if (workTimer.startedAt) return workTimer.startedAt;
  try {
    workTimer.startedAt = Number(sessionStorage.getItem(WORK_TIMER_KEY)) || 0;
  } catch {
    workTimer.startedAt = 0;   // 隐私模式之类读不到 sessionStorage，就当没在计时
  }
  return workTimer.startedAt;
}

function startWorkTimer() {
  workTimer.startedAt = Date.now();
  try {
    sessionStorage.setItem(WORK_TIMER_KEY, String(workTimer.startedAt));
  } catch {
    /* 存不下就只在这次会话里计着，不影响用 */
  }
}

function stopWorkTimer() {
  const minutes = elapsedMinutes(workTimerStartedAt(), Date.now());
  workTimer.startedAt = 0;
  try {
    sessionStorage.removeItem(WORK_TIMER_KEY);
  } catch {
    /* 上面没存下，这里也没什么好删的 */
  }
  return minutes;
}

/** 每秒把「00:12:34」刷一下。只改那一行字，不重画整页，免得一闪一闪 */
function startWorkTicker() {
  if (workTimer.tick || !workTimerStartedAt()) return;
  workTimer.tick = setInterval(() => {
    const box = document.getElementById("wk-timer");
    if (!box) {
      clearInterval(workTimer.tick);
      workTimer.tick = null;
      return;
    }
    const num = box.querySelector("b");
    if (num) num.textContent = clockText(workTimerStartedAt(), Date.now());
  }, 1000);
}

/** 工时页上那几个按钮（返回 true 表示这个事件归它管） */
function hoursAction(e, act) {
  if (act === "wk-add") {
    openWorkDialog(null, null);
    return true;
  }
  if (act === "wk-timer-start") {
    startWorkTimer();
    toast("开始计时，忙完点「停止并记录」");
    redraw();
    return true;
  }
  if (act === "wk-timer-cancel") {
    stopWorkTimer();
    toast("已取消计时");
    redraw();
    return true;
  }
  if (act === "wk-timer-stop") {
    const minutes = stopWorkTimer();
    redraw();
    // 计出来的分钟直接填进弹窗，确认一下（想挑项目、补备注都在这里）
    openWorkDialog(null, { duration: minutes, durationUnit: "分钟" });
    return true;
  }
  if (act === "wk-edit" || act === "wk-del") {
    const li = e.target.closest("[data-id]");
    const row = li ? table("workLogs").find((w) => w.id === li.dataset.id) : null;
    if (!row) return true;
    if (act === "wk-edit") openWorkDialog(row, null);
    else deleteWorkLog(row);
    return true;
  }
  return false;
}

async function deleteWorkLog(row) {
  const ok = await askConfirm({
    title: "删掉这笔工时？",
    message: `${row.note || row.date || "这笔工时"}\n\n会放进回收站，误删可以去「数据与设置」找回。`,
    confirmLabel: "删除",
    danger: true,
  });
  if (!ok) return;
  moveToTrash("workLogs", row, row.note || row.date || "");
  touch(true);
  toast("已移入回收站");
}
```
