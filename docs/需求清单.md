# 小李 · 需求清单

版本 v0.5 · 2026-10-07 · 状态：**已按此清单实现，并在用**

## 1. 一句话定位

只在你自己的 Windows 电脑上、用浏览器打开的个人 App。不登录、不联网、不上云、不做手机端、不需要部署。所有数据存在本机，刷新、关闭、重启电脑后都不丢。十个模块各管一件事，功能要贴合各自场景，**不是同一个任务列表换名字**。

## 2. 十个模块

首页总览 · 今日计划 · 自媒体 · 开发工作 · **学习工作** · **记账** · 健身计划 · 饮食计划 · 游戏娱乐 · 数据与设置

## 3. 第一版（v1）每个模块做到什么程度

原则：都能真正用起来，但每块只做「最小可用的那个场景功能」。图表、日历、提醒、标签体系这些统一往后放。

- 自媒体数据回收（粉丝、播放量）、素材库

- 热量与营养计算、菜谱库
- Steam 同步、成就追踪、追剧/看番清单
- 多用户与权限

## 5. 运行方式与数据存放（需要你二选一）

**方案 A（推荐）**：双击一个「启动」文件 → 电脑上起一个只在本机跑的小服务 → 浏览器自动打开界面 → 数据写进 app 文件夹里的数据文件。
优点：数据是看得见摸得着的文件，容量不受限，随便复制备份，最符合「重启也不能丢」。缺：需要双击启动文件，不是直接双击网页。

**方案 B**：直接双击网页文件打开。
优点：少一步。缺：浏览器对「本地文件」存数据限制很严（容量小、清缓存就没了），**无法保证重启不丢**。

结论：你的硬要求是「刷新、关闭、重启都不丢」，所以推荐 A。
