# 明暗「跟随系统」设计（2026-10-07）

## 要解决的问题

原来明暗只有浅色 / 深色两颗按钮，选完就固定住。系统在晚上自动变深色时，App 不会跟。
这次加第三种「跟随系统」，并把「策略」和「结果」拆开。

## 数据

```
settings.themeMode = "light" | "dark" | "system"   ← 策略（新增，互斥三选一）
settings.theme     = "light" | "dark"              ← 结果（老字段，继续保留）
data-theme         = "light" | "dark"              ← html 上的属性，CSS 只认它
```

- 新增 `themeMode`，默认 `light`（和以前一样，不改变已有用户的观感）；`服务.py`
  的空骨架和 `tools/演示数据.py` 都补上这个键。
- 老数据没有 `themeMode` 时按老的 `theme` 迁一次（`dark` → 深色，其余 → 浅色）。
  `applyTheme()` 顺手把它补进内存，所以这份文件下次一保存（改任何设置都算）就带上了新字段，
  不需要手动改 `数据.json`。
- `theme` 继续写一份「当前实际明暗」，老版本的数据文件也读得懂；CSS 一行没改，
  仍按 `html[data-theme]` 走，深色直接复用现有那套暗色液态玻璃。

## 逻辑（`app/web/theme.js`，纯函数）

| 函数 | 作用 |
| --- | --- |
| `normalizeThemeMode(value, legacy)` | 认得出就用，认不出退回 `light`（顺带从 `legacy` 迁） |
| `resolveTheme(mode, systemDark)` | 策略 + 系统偏好 → 实际明暗；`system` 读不到就浅色兜底 |
| `nextThemeMode(mode)` | 顶部快捷按钮的循环：浅色 → 深色 → 跟随系统 → 浅色 |

读系统偏好、改 DOM、落盘都在 `store.js`：`window.matchMedia('(prefers-color-scheme: dark)')`
挂 `change` 监听，回调里先看当前模式是不是 `system`——手动选了浅色 / 深色就不动，
等于停止跟随；另外挂 `visibilitychange`，从后台回来 / 睡眠唤醒补读一次。

## 界面

- **数据与设置 → 外观与标语 → 明暗**：浅色 / 深色 / 跟随系统三颗互斥按钮，
  跟随系统那颗带 tooltip（自动跟随电脑 Windows/macOS 系统明暗主题，切换系统主题时
  App 同步更新）；选中它时下面补一句小字，说明会实时跟着变。
- **右上角快捷按钮**：三态循环。图标画「点一下会变成什么」（浅色 🌙 / 深色 🖥 /
  跟随系统 ☀️），tooltip 说清当前模式，跟随系统时带上系统现在的明暗。
- 切模式后自动写盘（沿用现有 `touch(true)` 整份替换写盘），刷新、重开都在。

## 兜底

- 浏览器没有 `matchMedia` / `prefers-color-scheme`：跟随系统按浅色显示，
  按钮 tooltip 和小字都写明「读不到系统明暗」。
- 系统主题变了但页面在后台：回到前台补读一次。
- 数据文件里没有 `themeMode`：读的时候按 `theme` 迁，保存时自动补齐。
