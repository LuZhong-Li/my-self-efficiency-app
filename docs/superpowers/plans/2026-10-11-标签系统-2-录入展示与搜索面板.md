# 标签系统（二）：录入、展示、搜索面板 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让标签真的能用：统一弹窗里能填、列表行上看得见、搜索面板里点一个标签
就把全站带它的记录捞出来。

**Architecture:** 纯逻辑（`tag-calc.js` 的清洗 / 颜色、`search-calc.js` 的
`allTags` / `searchByTag`）和迁移在前一份计划里已经立住，这一份只做三件事：
① `item-form.js` 的字段表加一种 `tags` 字段（一次覆盖 9 个表单）；
② `ui.js` 一个 `tagChips()` 把标签画成胶囊，逐页挂到列表行上；
③ 搜索面板加一行标签区，点一下调 `searchByTag()`。所有取值、回填、校验都走
纯函数，页面只管画和接事件。

**Tech Stack:** 原生 HTML + CSS + ES 模块（无框架、无构建、零外链）；
测试用 Node（纯逻辑 + 表单字段表）+ 无头 Edge 的 CDP 回归（真点一遍）。

**Spec:** `docs/superpowers/specs/2026-10-11-标签系统-design.md`（动手前先读一遍）
**前置：** `docs/superpowers/plans/2026-10-11-标签系统-1-纯逻辑与迁移.md`
必须先做完（那份给的名字与数据形状，这一份直接用）。

## Global Constraints

- **零外链**：界面文件里不能出现任何 `http(s)://` 链接；`tests/自检.py` 会扫。
- **不装依赖**：Node 只用来跑 `tests\*.test.mjs`（直接 `node 文件名`）。
- **读标签一律走 `tagsOfRow(row)`**，画标签一律走 `tagChips(row)`：
  不许在页面里直接读 `row.tags`、也不许自己拼胶囊的 HTML。
- **上限只有一个定义**：`TAG_MAX_CHARS` / `TAG_LIMIT` / `TAG_PALETTE` 都在
  `tag-calc.js`，页面与提示文案里不许再写死数字。
- **颜色只用 CSS 变量**：胶囊取 `--tag`（由 `data-c="1"…8"` 决定），
  色值沿用全站那套分类色，四套皮肤 × 深浅两色都不能破相。
- **事件不挂公共 `#view`**：一律 `bindFresh(root, {...})`。
- **增删改走 `touch(true)` 立刻落盘**。
- **注释与提交信息用中文**，说清「为什么」。
- 每个任务结束：本任务对应的 `node tests\*.test.mjs` 与 `python tests\自检.py`
  都要过；碰了页面的任务还要跑一遍 `node tests\弹窗栈.test.mjs` 与
  `node tests\搜索交互.test.mjs`（无头 Edge），浏览器控制台 0 条 error。

④ 文件末尾加这个函数：

```js
/**
 * 标签输入框下面那行实时预览：边打边看「现在收成了哪几个标签」，
 * 顺手把「超量 / 单个太长」也当场说出来（保存时 validate 还会再拦一道）。
 * 只改这一小块，不重画弹窗 —— 重画会把已经填了一半的内容弄丢。
 */
function bindTagPreview(el, spec) {
  for (const field of spec.fields.filter((f) => f.kind === "tags")) {
    const input = el.querySelector("#item-" + field.name);
    const box = el.querySelector(`[data-tags-preview="${field.name}"]`);
    if (!input || !box) continue;
    const sync = () => {
      const list = normalizeTags(input.value);
      const err = tagInputError(input.value);
      box.classList.toggle("over", Boolean(err));
      box.innerHTML =
        (list.length
          ? list
              .map((name) =>
                `<span class="chip tag-chip" data-c="${tagColor(name)}">${esc(name)}</span>`)
              .join("")
          : `<span class="dlg-tags-hint">逗号分开，最多 ${TAG_LIMIT} 个</span>`) +
        (err ? `<span class="dlg-tags-err">${esc(err)}</span>` : "");
    };
    input.addEventListener("input", sync);
    sync();          // 编辑老记录时进来就先把已有的标签画出来
  }
}
```

注意：**回车仍然是「保存」**（`bindEnterToSave` 不动，和其它输入框一致），
标签之间用逗号 / 顿号分开就行。

- [ ] **Step 1: `ui.js` 加一个画胶囊的函数**

顶部 import 补上：

```js
import { tagsOfRow, tagColor, visibleTags } from "./tag-calc.js";
```

`priorityChip()` 之后加：

```js
/**
 * 标签胶囊：一条记录贴的标签画成小胶囊，最多画 max 个，剩下的收成 +N
 * （鼠标移上去 title 里能看到全部）。没标签就返回空串，不占位。
 * 颜色由名字哈希取（tag-calc.js 的 tagColor），不落盘、不用配。
 */
export function tagChips(row, max = 3) {
  const tags = tagsOfRow(row);
  if (!tags.length) return "";
  const { shown, rest } = visibleTags(tags, max);
  return (
    shown
      .map((name) => `<span class="chip tag-chip" data-c="${tagColor(name)}">${esc(name)}</span>`)
      .join("") +
    (rest > 0
      ? `<span class="chip tag-chip tag-more" title="${esc(tags.join("、"))}">+${rest}</span>`
      : "")
  );
}
```

```js
  /** 顶栏那一行：全站已经出现过的标签，点了就只看带它的记录 */
  function tagRowHtml() {
    const list = allTags(store.data).slice(0, 12);
    if (!list.length) return "";
    return `<div class="sr-tags">${
      list
        .map((t) => `<button class="sr-tag-chip${t.name === activeTag ? " on" : ""}"` +
          ` data-tag="${esc(t.name)}" title="${esc(t.count)} 条">${esc(t.name)}</button>`)
        .join("")
    }</div>`;
  }

  function archiveHtml() {
    return `<label class="sr-archive">
      <input type="checkbox" id="search-archived"${includeArchived ? " checked" : ""}>
      包含归档记录
    </label>`;
  }

  /** 结果列表；没找到时那句要把「标签 + 关键词」都说清楚 */
  function panelHtml(hits, query) {
    if (!hits.length) {
      const what = activeTag
        ? (query ? `「${esc(activeTag)}」里的「${esc(query)}」` : `贴了「${esc(activeTag)}」的`)
        : `「${esc(query)}」`;
      return `<div class="sr-none">没找到${what}</div>`;
    }
    return hits
      .map(
        (h) => `<button class="sr-item" data-module="${esc(h.module)}" data-hash="${esc(h.hash || h.module)}">
          <span class="sr-tag">${esc(h.label)}</span>
          <span class="sr-text">${highlight(h.text, query.trim())}</span>
        </button>`
      )
      .join("");
  }
```

```js
      return;

  }
```
