# 热量营养计算 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 饮食模块从「记吃了什么」升级到「也算得出吃了多少」：菜谱库存每份的营养，每餐从库里挑、填份数，今日热量与三大营养素自动汇总，能配每日目标并看近 7 天趋势。

**Architecture:** 饮食这一块新建纯逻辑模块 `app/web/diet-calc.js`（原来散在页面里的几个小函数一并收进来）；菜谱是新表 `data.foods`，每餐的条目挂在 `meals[].items` 上（**存「每份」的营养快照**，改菜谱不动历史账）；界面还是 `diet.js`，加一排子 Tab 和一个菜谱库子页；柱状图复用 `chart-calc.js`；两个新表单类型走 `item-form.js`，其中「选名字自动带出营养」是 `item-dialog.js` 里新加的小机制 `bindAutoFill`。

**Tech Stack:** 原生 HTML/CSS/ES 模块（无框架、无构建、零外链）；Python 3 标准库小服务；测试用 Node 22+ 内置 `fetch` / `WebSocket` 直连 CDP 驱动无头 Edge。

**Spec:** `docs/superpowers/specs/2026-10-14-热量营养-design.md`

## Global Constraints

- **零外链**：任何 `.html` / `.css` / `.js` 里不许出现 `http://` 或 `https://` 字面量（`tests\自检.py` 的 `check_no_external()` 会正则扫）。
- **老数据迁移只补不改**：缺了才补默认值，已经有了的一个字节都不动（`app/服务.py` 的 `normalize_data`）。
- **一个任务一个提交**，commit message 用中文；直接提交到 `main`。
- 注释用中文，写「为什么这么写」。
- 每改完一处至少跑：`node tests\<相关>.test.mjs` 和 `& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" tests\自检.py`。
- 测试断言写错就改测试，不改实现。
- 条目里存的是**每 1 份**的营养（不是「这一条一共多少」）；汇总时先按原值相加、最后四舍五入到整数。
- 四餐的键固定 `breakfast` / `lunch` / `dinner` / `snack`，页面上叫早 / 午 / 晚 / 加餐。
- **不动四餐那四个文字输入框**（「随手写一句」是有用的）。

```js
/* 饮食的纯逻辑：菜谱长什么样、一条「吃了什么」长什么样、按份数换算营养、
 * 一天的合计、近几天的热量趋势、每日目标的档位。
 *
 * 原来的饮食页只有「四餐文字 + 水杯数」，那几个小函数散在页面里；这一轮加营养计算，
 * 顺手收成一个纯逻辑模块 —— 热量这块最容易算错，`node tests\饮食计算.test.mjs`
 * 能一条条断言（和记账、工时那几个计算模块一个路数）。
 *
 * 两个形状分清楚：
 *   · 菜谱（foods 表）——「一样东西每份多少热量 / 蛋白 / 脂肪 / 碳水」；
 *   · 条目（meals[].items）——「这一餐吃了哪样、几份」，营养是**每 1 份的快照**。
 *     存快照的理由：份数改了营养跟着走，而改菜谱不会动摇历史账。
 */

import { barRatioOf } from "./chart-calc.js";

/** 四餐：键（存数据用）与页面上的名字 */
export const DIET_SLOTS = [
  ["breakfast", "早餐"],
  ["lunch", "午餐"],
  ["dinner", "晚餐"],
  ["snack", "加餐"],
];

const SLOT_KEYS = DIET_SLOTS.map((s) => s[0]);

function num(value) {
  const n = Number(value);
  return Number.isFinite(n) ? n : 0;
}

function text(value) {
  return String(value == null ? "" : value).trim();
}

/** 认不出的餐次一律算加餐（老数据、手改过的都不丢） */
function slotOf(value) {
  const key = text(value);
  return SLOT_KEYS.includes(key) ? key : "snack";
}

/** 把一条菜谱补齐成完整形状 */
export function normalizeFood(row) {
  const r = row && typeof row === "object" ? row : {};
  return {
    id: text(r.id),
    name: text(r.name),
    unit: text(r.unit),
    kcal: Math.max(0, num(r.kcal)),
    protein: Math.max(0, num(r.protein)),
    fat: Math.max(0, num(r.fat)),
    carb: Math.max(0, num(r.carb)),
    tags: Array.isArray(r.tags) ? r.tags.map((t) => text(t)).filter(Boolean) : [],
    note: text(r.note),
  };
}

/** 把一条「吃了什么」补齐成完整形状。份数没填按 1 份算；写成 0 / 负数就按 0。 */
export function normalizeMealItem(row) {
  const r = row && typeof row === "object" ? row : {};
  const rawAmount = r.amount;
  const blank = rawAmount === undefined || rawAmount === null || rawAmount === "";
  return {
    id: text(r.id),
    slot: slotOf(r.slot),
    foodId: text(r.foodId),
    name: text(r.name),
    unit: text(r.unit),
    amount: blank ? 1 : Math.max(0, num(rawAmount)),
    kcal: Math.max(0, num(r.kcal)),
    protein: Math.max(0, num(r.protein)),
    fat: Math.max(0, num(r.fat)),
    carb: Math.max(0, num(r.carb)),
  };
}

/** 这一餐的条目（meal 可能是 null / 老数据没有 items） */
export function itemsOfSlot(meal, slot) {
  const want = slotOf(slot);
  const list = meal && Array.isArray(meal.items) ? meal.items : [];
  return list.map((r) => normalizeMealItem(r)).filter((i) => i.slot === want);
}

/**
 * 按份数换算求和。**先按原值相加、最后再四舍五入**到整数 ——
 * 一条条先取整再加，误差会攒起来。
 */
export function nutritionOf(items) {
  const sum = { kcal: 0, protein: 0, fat: 0, carb: 0 };
  for (const raw of items || []) {
    const it = normalizeMealItem(raw);
    sum.kcal += it.kcal * it.amount;
    sum.protein += it.protein * it.amount;
    sum.fat += it.fat * it.amount;
    sum.carb += it.carb * it.amount;
  }
  return {
    kcal: Math.round(sum.kcal),
    protein: Math.round(sum.protein),
    fat: Math.round(sum.fat),
    carb: Math.round(sum.carb),
  };
}

/** 那一天的记录（meals 里 date 对上的那条） */
function mealOf(meals, date) {
  const day = text(date);
  return (meals || []).find((m) => m && text(m.date) === day) || null;
}

/** 那一天四餐加起来（没记过那天就全是 0） */
export function dayNutritionOf(meals, date) {
  const meal = mealOf(meals, date);
  return nutritionOf(meal && Array.isArray(meal.items) ? meal.items : []);
}

/** 这几天每天的热量 + ratio（给柱状图；和 gameMonthTrend 一个形状） */
export function dayKcalSeries(meals, dates) {
  const list = Array.isArray(dates) ? dates : [];
  const values = list.map((d) => dayNutritionOf(meals, d).kcal);
  const max = values.reduce((best, v) => Math.max(best, v), 0);
  return list.map((date, i) => ({
    date: text(date),
    kcal: values[i],
    ratio: barRatioOf(values[i], max),
  }));
}

/** 每日目标（存 settings.nutritionTarget）：读数补成完整形状，缺的当 0（= 不设） */
export function nutritionTargetOf(data) {
  const raw = (data && data.settings && data.settings.nutritionTarget) || {};
  return {
    kcal: Math.max(0, num(raw.kcal)),
    protein: Math.max(0, num(raw.protein)),
    fat: Math.max(0, num(raw.fat)),
    carb: Math.max(0, num(raw.carb)),
  };
}

/**
 * 热量档位：没设目标 → none（只报数、不画进度条）；不到 80% → low；
 * 80% 到 100% → good；超了 → over（页面标红）。
 * percent 不封顶（超了多少要有数可查），diff 正数是「还差多少」、负数是「超了多少」。
 */
export function kcalStateOf(total, target) {
  const eaten = Math.max(0, num(total));
  const goal = Math.max(0, num(target));
  if (!goal) return { level: "none", percent: 0, diff: 0, over: false };
  const percent = Math.round((eaten / goal) * 100);
  const over = eaten > goal;
  return {
    level: over ? "over" : percent >= 80 ? "good" : "low",
    percent,
    diff: goal - eaten,
    over,
  };
}
```

```js
/**
 * 「选了一样东西，把别的几格自动带出来」—— 比如「吃了什么」里选了菜谱库里的「米饭」，
 * 后面的每份热量 / 蛋白 / 脂肪 / 碳水 / 单位就自动填上（填完还能自己改）。
 *
 * 声明方式：字段写 `autoFill: "foods"`，弹窗的 ctx.autoFill.foods 是「名字 → 资料」。
 * 只认 input/change（不是每次按键都查），免得把正在打字的人打断。
 */
function bindAutoFill(el, spec, ctx) {
  const targets = spec.fields.filter((f) => f.autoFill);
  if (!targets.length) return;
  const source = targets[0];
  const src = el.querySelector("#item-" + source.name);
  const table = (ctx && ctx.autoFill) || null;
  if (!src || !table) return;
  const box = table[source.autoFill];
  if (!box) return;
  // 只在「换了一个名字」时带一次：用户接下来自己改的数不再被覆盖
  let last = String(src.value || "").trim();
  const fill = () => {
    const now = String(src.value || "").trim();
    if (now === last) return;
    last = now;
    const hit = box[now];
    if (!hit) return;
    for (const field of targets) {
      if (field === source) continue;
      const input = el.querySelector("#item-" + field.name);
      if (!input || hit[field.name] === undefined) continue;
      input.value = String(hit[field.name]);
    }
  };
  src.addEventListener("change", fill);
  src.addEventListener("input", fill);
}
```

```js
async function deleteMealItem(item) {
  const ok = await askConfirm({
    title: "删掉这一条？",
    message: `${item.name || "这一条"}\n\n只从这一餐里去掉了，不进回收站。`,
    confirmLabel: "删除",
    danger: true,
  });
  if (!ok) return;
  const meal = table("meals").find((m) => m.date === selected);
  if (meal && Array.isArray(meal.items)) {
    const index = meal.items.indexOf(item);
    if (index >= 0) meal.items.splice(index, 1);
  }
  touch(true);
}

    confirmLabel: "删除",
    danger: true,
  });
  if (!ok) return;
  moveToTrash("foods", row, row.name || "");
  touch(true);
  toast("已移入回收站");
}
```
