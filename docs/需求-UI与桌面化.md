## 2. 桌面化需求（D 组）

### D-1 启动不再弹黑色命令行窗口

**现状**：双击 `启动.cmd` → cmd 黑窗口（找 Python、跑服务、窗口常驻，关窗即停）。

**目标**：双击后不出现任何控制台窗口；应用以窗口方式运行。

**验收点**：
1. 双击启动文件后，屏幕上不出现 cmd/黑色控制台窗口；
2. 若 Python 或依赖缺失，仍有可见的报错提示（不能静默失败）；
3. 服务正常起来，窗口正常出现。

**做法方向**（详见计划文档）：
- 服务以 `pythonw.exe`（无控制台版解释器）启动；
- 保留「带控制台」的调试入口（如 `启动-调试.cmd`，用于看日志排错）。

### D-2 应用拥有独立窗口，不再占用浏览器标签

**现状**：服务启动后 `webbrowser.open` 打开默认浏览器标签。

**目标**：默认不再开浏览器，而是打开一个小李自己的桌面窗口（WebView2 渲染，内容与浏览器一致）。

**验收点**：
1. 双击启动 → 出现标题为「小李」的独立窗口，任务栏有独立图标；
2. 窗口内渲染的就是现在的小李界面，所有模块、搜索、弹窗、拖拽、明暗切换行为与浏览器一致；
3. 不弹出默认浏览器，不新增标签页；
4. 窗口可缩放、可最大化、可最小化，最小尺寸生效；
5. 窗口关闭后，后台服务一并退出，不留残留进程（`netstat` 查端口应已释放）。

### D-3 桌面模式缺依赖时自动回退浏览器模式

**现状**：当前零第三方依赖（标准库 http.server）。

**目标**：桌面化引入 pywebview 依赖后，缺失时不能挡住使用。

**验收点**：
1. 装有 pywebview：桌面窗口模式；
2. 未装 pywebview（或 import 失败）：自动回退「浏览器模式」（行为等同今天的启动.cmd），并打一行提示（控制台/日志）；
3. 回退不影响数据、不影响任何功能。

### D-4 窗口标题、图标、默认尺寸

**验收点**：
1. 窗口标题「小李」；
2. 窗口图标用现有 `小李.ico`；
3. 默认尺寸 1280×860（待拍板），最小尺寸不小于 960×640，避免布局挤压；
4. 窗口尺寸记忆（可选：记住上次关闭时的大小，待拍板）。

### D-5 关闭窗口即退出，数据不丢

**现状**：数据每次操作即落盘（前端请求 /api/save），退出不依赖「保存」动作。

**验收点**：
1. 关闭窗口 → 服务进程退出，端口释放；
2. 关闭前最后几秒内的操作已落盘（抽查：改一条数据 → 立即关窗 → 重开，数据在）；
3. 退出过程不留孤儿 python 进程（任务管理器无残留）。

## 3. UI 设计感需求（U 组）

> 实现策略统一为：**CSS 变量（设计令牌）增量覆盖 + 只增不改（不删既有规则、不改既有选择器）**，逐模块走查验收。所有截图对比以「改前/改后」成对提交到 `docs/screenshots/`。

### U-1 背景 / 顶栏 / 侧栏 / 卡片的视觉质感升级

**现状**：背景纯色 `#f5f6f8`（深色 `#111827`）；顶栏/侧栏/卡片为纯色块 + 细边框；卡片阴影单档。

**目标**：
1. 背景：浅色为柔和的低饱和渐变（微蓝紫），深色为有深度的渐变，不做刺眼高饱和；
2. 顶栏/侧栏：半透明毛玻璃质感（backdrop-filter 模糊 + 半透明底色 + 高光描边），滚动内容时可见层次；
3. 卡片：两级阴影体系（常态 / hover 抬升），hover 有轻微位移与高光边；选中/进行中状态有强调色描边；
4. 深色下玻璃质感必须明显（浅色下克制，保持清爽）。

**验收点**：
1. 明暗两套分别截图，与 `docs/screenshots/home-light.png`（现状）对比，质感差异肉眼可辨；
2. 滚动主内容区时顶栏/侧栏的玻璃模糊生效（截图为证）；
3. 卡片 hover 有反馈（位移 + 阴影 + 高光，三选二以上）。

### U-2 模块主题色体系

**目标**：为 11 个模块各配一个主题色（首页 / 今日计划 / 自媒体 / 开发工作 / 学习工作 / 记账 / 健身 / 饮食 / 游戏 / 笔记 / 数据设置），用于：侧栏图标底色、模块卡片强调条、标签、进度条、统计数字。颜色必须明暗两套都够对比度。

**验收点**：
1. 侧栏每个模块的图标有主题色底/描边，一眼区分；
2. 各模块首页卡片有主题色强调元素（如左侧 4px 色条或图标色）；
3. 主题色全部取自 CSS 变量，无散落的硬编码色值；
4. 深色模式下所有主题色仍可辨识（对比度 ≥ 3:1 文字场景）。

### U-3 排版层级与数字等宽

**目标**：
1. 品牌「小李」、区块标题、卡片标题、正文、辅助文字的字号/字重/颜色层级清晰；
2. 数字（金额、统计、进度百分比）用等宽数字特性（`font-variant-numeric: tabular-nums`），同列数字对齐；
3. 标题与正文间距节奏统一（间距仍以 8px 为基准）。

**验收点**：
1. 任一统计卡片内数字逐行对齐（截图抽查）；
2. 全站标题层级无「都一样大」的页面（走查 11 个模块）。

### U-4 动效体系

**目标**（全部尊重 `prefers-reduced-motion: reduce`，用户系统开启减弱动效时全部关闭）：
1. 页面/视图切换：淡入 + 轻微上移（≤ 200ms）；
2. 卡片 hover：阴影与位移过渡（≤ 150ms）；
3. 弹窗：scale 0.96→1 + fade 进场（≤ 180ms），关闭反向；
4. 按钮：按下微缩（scale 0.98）+ hover 色过渡；
5. 列表项增删：不超过 150ms 的淡出/滑入（可选，P2）。

**验收点**：
1. 打开任一二级弹窗有进场动效；
2. 系统开启「减弱动态效果」后所有动效消失（截图/录屏为证）；
3. 动效不阻塞交互（不设长延迟），不使用会让 46 个测试选择器失效的动画类名。

### U-5 细节质感

**目标**：
1. 空状态：无数据列表显示内联 SVG 小插图 + 一句话 + 引导按钮（内联，不联网）；
2. 聚焦环：输入框/按钮聚焦时有统一、清晰的聚焦样式（不依赖默认 outline）；
3. 选中态：侧栏当前模块、卡片选中、表格行选中，样式统一；
4. 图标：全站图标统一为同一线性风格（基于现有 `icons.js`，补齐缺的图标，不换库）；
5. 滚动条：已统一细胶囊，保持不动。

**验收点**：
1. 找一个空列表（如无任何记账时）截图，空状态完整；
2. Tab 键遍历焦点，聚焦环清晰可见；
3. 图标风格抽 5 个模块对比，无混用风格。

## 4. 明确不做（本轮）

- 自定义标题栏 / frameless 窗口（留作后续）；
- 系统托盘常驻、开机自启（后续可选，本轮不做）；
- 联网功能、在线字体图标、云同步、手机端；
- 改数据格式、数据迁移、动数据集功能；
- 重写 style.css（只增量、只变量化）；
- 改任何测试断言的 DOM 选择器依赖（若个别断言必须适配，需单独评审）。
