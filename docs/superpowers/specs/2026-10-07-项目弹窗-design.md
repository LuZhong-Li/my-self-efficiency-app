# 开发工作「添加项目」改成弹窗（2026-10-07）

## 要解决的问题

第 26 节把六个模块的录入改成弹窗之后，开发工作页顶上还剩最后一行平铺输入框
——「添加项目」（项目名 + 状态 + 一句话简介 + 开始日期）。它是一行四个控件，
写不下项目目标和规划，图片也没地方放。

这次把这一处也搬进弹窗，用的是同一套 `openItemDialog()`，
type 新增 `devProject`。改完之后，开发工作页的**三种录入（项目 / 待办 / 问题）**
全是弹窗了。

## 一、数据

`projects[]` 扩三个字段（老字段 `intro`「一句话简介」名字不动，老数据零成本）：

```
description    详细描述（多行）：目标、规划、怎么算做完
expectEndDate  预计结束日期
imagePaths     图片，存 attachments/dev_project/
```

服务端 `migrate()` 给老项目补空串 / 空数组。状态词从两个扩到四个：
**进行中 / 已暂停 / 已完成 / 废弃**（原来的进行中、已完成照旧）。

## 二、弹窗

标题：新增项目 / 编辑项目。字段：

| 字段 | 说明 |
| --- | --- |
| 项目名称 | 单行，必填 |
| 状态 | 下拉：进行中 / 已暂停 / 已完成 / 废弃 |
| 开始日期 | 日期；新增时默认填今天（不想要就清掉） |
| 一句话简介 | 单行（还是老的 `intro` 字段） |
| 详细描述 | 多行，最多 2000 字 |
| 预计结束日期 | 日期，可不填 |
| 图片附件 | `+ 添加图片备注`，存 `attachments/dev_project/` |

新增 / 编辑共用这一个弹窗；编辑时多一个「删除」。

**删除的连带规则**写进了 `trashPlan()`：删项目要带走它的待办（靠
`belong === "dev:<id>"` 认）、问题、进展，确认框里会写清带走几条。
详情页那个「删除项目」按钮也改成走同一个 `trashItem()`，不再各写一份。

## 三、页面

- 卡片顶上那行输入框没了，换成卡片头右上角的「添加项目」；
- **筛选栏原样保留**（关键词 + 状态下拉 + 清空筛选），只是状态下拉多出
  「已暂停 / 废弃」两项；
- 项目卡片：原来只在有开始日期时显示一行「开始于 …」，现在开始日期和预计结束
  一起显示（「开始于 2026-08-30 · 预计 2026-11-21 收尾」）；
- 卡片右上角有图片时多一个小标记，**点它是看大图**（`openPathViewer`），
  点卡片别处还是进项目详情 —— 标记上挂 `data-act="p-img"`，
  处理时 `preventDefault()` 掉链接的默认跳转；
- 项目详情页：字段里多一行「预计结束」，详细描述按原样保留换行显示在字段下面，
  有图片就在下面铺一行缩略图。

## 四、没做的

需求里没提、这次也没加的：项目的拖拽排序（早就有）、按预计结束日期提醒、
项目归档 / 复刻。

## 五、验证

- `node tests\表单计算.test.mjs`：110 → **137 项**（`devProject` 的字段表、
  状态四选一、描述是多行、默认值、必填、编辑回填、新增空壳、
  以及删项目的连带计划：1 条待办 + 1 个问题 + 1 条进展只带走属于它的、
  提示语按类型区分）。
- `python tests\自检.py`：57 → **60 项**（图片能存进 `attachments/dev_project/`、
  老项目补齐 `description` / `expectEndDate` / `imagePaths`、
  老项目的「一句话简介」还是 `intro` 没被改名）。
- 浏览器里手工验：项目页没有平铺输入行了、筛选栏还在、状态多了两项；
  点卡片上的图片标记看大图且不跳页；添加项目（填全六个字段 + 描述换行）→
  卡片和详情页都对；编辑回填；从弹窗删项目 → 回收站里项目 + 它的 4 条待办 /
  问题 / 进展一起进来，确认语写的是「4 条待办 / 问题 / 进展」不再是「学习记录」；
  粗野 + 深色下无横向溢出、控制台 0 报错。
