# 素材库（全站版）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把自媒体那个素材库升成全应用共用的：素材搬到顶层 `assets`（图片 / 链接 / **文本片段**三种），任何模块的记录都能引用（只存素材 id），素材那页能看出「被 N 处引用」，删素材时把各处的引用摘干净。

**Architecture:** 纯逻辑新开 `app/web/asset-calc.js`（现有的四个函数从 `media-calc.js` 搬过来并扩成跨表，原处只留一行转出）；记录那一侧统一用 `assetIds: []` 存 id；弹窗里新增 `kind: "assets"` 控件（隐藏 input 存 JSON，和子任务一个路子）；素材页面与素材弹窗还在 `media.js`（`#media/assets`），加第三档类型。

**Tech Stack:** 原生 HTML/CSS/ES 模块（无框架、无构建、零外链）；Python 3 标准库小服务；测试用 Node 22+ 内置 `fetch` / `WebSocket` 直连 CDP 驱动无头 Edge。

**Spec:** `docs/superpowers/specs/2026-10-14-素材库全站版-design.md`

## Global Constraints

- **零外链**：任何 `.html` / `.css` / `.js` 里不许出现 `http://` 或 `https://` 字面量（`tests\自检.py` 的 `check_no_external()` 会正则扫）。素材里的链接是**用户数据**，渲染时照旧走 `esc`。
- **老数据迁移只补不改**：`mediaAssets` 是「搬家」（id 不变、内容不动），别的表只补 `assetIds: []`。
- **一个任务一个提交**，commit message 用中文；直接提交到 `main`。
- 注释用中文，写「为什么这么写」。
- 每改完一处至少跑：`node tests\<相关>.test.mjs` 和 `& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" tests\自检.py`。
- 测试断言写错就改测试，不改实现。
- **记录那一侧只存素材 id**（`assetIds`）；素材本身删掉时，各处的引用要摘掉。

```js
/* 素材库（全站版）的纯逻辑：一条素材长什么样、读出来、被几处引用、删素材时摘引用。
 *
 * 素材原来只有自媒体在用（mediaAssets 表、只数「用在几条作品上」）。2026-10-14 升级成
 * 全站共用：搬到顶层 data.assets，加了「文本片段」这一种类型，引用计数与摘引用都跨表走。
 * 这几个函数本来在 media-calc.js 里，一并搬过来（那边只留一行转出，页面和测试不用改）。
 *
 * 老数据兼容：老的 mediaAssets 表照样认（搬家还没落盘那一刻两个都在），
 * 同一个 id 以顶层那份为准。
 */

export const ASSET_KINDS = ["image", "link", "text"];

/** 能挂素材的表（表名 + 页面上的叫法）；"finance.transactions" 这种带点的照 readTable 那套取 */
export const ASSET_TABLES = [
  ["contents", "作品"],
  ["tasks", "待办"],
  ["issues", "问题"],
  ["projects", "项目"],
  ["studies", "学习记录"],
  ["subjects", "学习对象"],
  ["workoutLogs", "训练打卡"],
  ["gameRecords", "游玩记录"],
  ["notes", "笔记"],
  ["finance.transactions", "账目"],
];

function text(value) {
  return String(value == null ? "" : value).trim();
}

/** 照着 "finance.transactions" 这种路径取表；取不到就给空数组 */
function readTable(data, key) {
  if (!data) return [];
  const parts = String(key).split(".");
  let holder = data;
  for (const part of parts.slice(0, -1)) {
    holder = holder[part];
    if (!holder || typeof holder !== "object") return [];
  }
  const rows = holder[parts[parts.length - 1]];
  return Array.isArray(rows) ? rows : [];
}

/** 把一条素材补齐成完整形状（认不出的类型当链接 —— 老数据只有图片和链接两种） */
export function normalizeAsset(row) {
  const r = row && typeof row === "object" ? row : {};
  const kind = ASSET_KINDS.includes(text(r.kind)) ? text(r.kind) : "link";
  return {
    id: text(r.id),
    title: text(r.title),
    kind,
    path: text(r.path),
    url: text(r.url),
    text: text(r.text),
    note: text(r.note),
    tags: Array.isArray(r.tags) ? r.tags.map((t) => text(t)).filter(Boolean) : [],
    createdAt: text(r.createdAt),
  };
}

/** 全部素材：顶层 assets 为准，老的 mediaAssets 也认（同 id 只留顶层那份） */
export function assetsOf(data) {
  const out = [];
  const seen = new Set();
  for (const row of [...readTable(data, "assets"), ...readTable(data, "mediaAssets")]) {
    if (!row || typeof row !== "object") continue;
    const one = normalizeAsset(row);
    if (seen.has(one.id)) continue;
    seen.add(one.id);
    out.push(one);
  }
  return out;
}

/** 一条记录引用了哪几个 id（老记录没这一格就当空） */
function idsOf(row) {
  const raw = row && Array.isArray(row.assetIds) ? row.assetIds : [];
  return raw.map((x) => text(x)).filter(Boolean);
}

/**
 * 每条素材被全站几处引用：{ [assetId]: { total, byTable } }。
 * 同一处写两遍只算一次，认不出的 id 不算（它没对应任何素材）。
 */
export function assetUsage(data) {
  const known = new Set(assetsOf(data).map((a) => a.id));
  const counts = new Map();   // assetId → Map<表名, 条数>
  for (const [key] of ASSET_TABLES) {
    for (const row of readTable(data, key)) {
      for (const id of new Set(idsOf(row))) {
        if (!known.has(id)) continue;
        const mine = counts.get(id) || new Map();
        mine.set(key, (mine.get(key) || 0) + 1);
        counts.set(id, mine);
      }
    }
  }
  const out = {};
  for (const asset of assetsOf(data)) {
    const mine = counts.get(asset.id) || new Map();
    const byTable = {};
    let total = 0;
    for (const [key, n] of mine) {
      byTable[key] = n;
      total += n;
    }
    out[asset.id] = { total, byTable };
  }
  return out;
}

/** 一条记录引用的那几份素材（查不到的跳过，不编空壳） */
export function assetsOfRow(row, assets) {
  const ids = new Set(idsOf(row));
  if (!ids.size) return [];
  return (assets || []).filter((a) => a && ids.has(a.id)).map((a) => normalizeAsset(a));
}

/**
 * 从所有表里摘掉这条素材的引用，返回摘掉了几处。
 * 删素材时用：素材没了，各处指着它的 id 就是脏数据，得一并清掉。
 */
export function unlinkAsset(data, assetId) {
  const id = text(assetId);
  if (!id) return 0;
  let removed = 0;
  for (const [key] of ASSET_TABLES) {
    for (const row of readTable(data, key)) {
      if (!row || !Array.isArray(row.assetIds)) continue;
      if (!idsOf(row).includes(id)) continue;
      row.assetIds = row.assetIds.filter((x) => text(x) !== id);
      removed += 1;
    }
  }
  return removed;
}
```

    # id 不变（各表里那些 assetIds 的引用自然还成立），内容不动，并完把老表清空。

/** 隐藏 input 里的 id 数组 JSON → 干净的字符串数组（坏 JSON 当空的、去重、去空） */
export function parseAssetJson(raw) {
  let list;
  try {
    list = JSON.parse(String(raw == null ? "" : raw) || "[]");
  } catch {
    return [];
  }
  if (!Array.isArray(list)) return [];
  return [...new Set(list.map((x) => String(x == null ? "" : x).trim()).filter(Boolean))];
}

/** 反过来：编回那条隐藏 input 的值 */
function encodeAssets(list) {

  );
}
