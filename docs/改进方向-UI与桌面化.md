# 小李 · 改进方向（UI 设计感 + 桌面化）

版本 v1.0 · 2026-10-15 · 状态：方向草案，待确认后拆需求与计划

## 1. 一句话目标

小李目前是「双击 `启动.cmd` → 弹一个黑窗口 → 自动开浏览器 → 在浏览器标签里用」。这一轮把它改造成：

1. **不弹黑窗口** —— 双击后没有命令行窗口一闪而过；
2. **不占浏览器** —— 有一个属于小李自己的应用窗口（像桌面软件一样，有窗口标题、图标、能固定到任务栏）；
3. **更有设计感** —— 前端视觉从「能用、干净」升级到「耐看、有质感」，明暗两套都要好看。

同时一条底线不变：**所有现有功能、数据、测试行为不被破坏**（46 个测试文件全绿是硬验收线）。

---

## 2. 三条改进主线

### 主线一：桌面化（自有窗口，不进浏览器）

| 现状 | 目标 |
| --- | --- |
| 双击 `.cmd`，弹黑色控制台窗口 | 双击后只有一个小李窗口，没有控制台 |
| 界面在浏览器标签页里，和别的网页混在一起 | 独立应用窗口，任务栏独立图标，像普通桌面软件 |
| 窗口标题是浏览器标签 | 窗口标题「小李」，可带自己的图标 |
| 关黑窗口 = 停服务 | 关应用窗口 = 退出程序（数据每次操作即落盘，不依赖退出） |

技术方向（详见调研文档）：**pywebview（WebView2）** 为主选 —— 纯 Python 依赖、直接套现有 HTTP 服务、Windows 10/11 自带 WebView2 Runtime、窗口极小。Electron/Tauri 太重，与「零外链、轻量本地工具」的定位不符。

**关键设计原则：桌面化必须是「可选外壳」，不是「唯一入口」。**
- 缺失依赖（比如 pywebview 没装）时自动回退到现在的「浏览器模式」，双击依然能用；
- 测试体系（46 个测试文件走无头 Edge + 临时目录直连 HTTP 端口）完全不受影响，服务层保持无 GUI 也能跑。

### 主线二：UI 设计感升级

现状：功能完整、布局清爽、双主题、液态玻璃元素已有雏形，但视觉整体偏「工具感」——白卡片铺底、列表文字为主、缺少层次与质感、几乎没有动效。

升级方向（详见需求文档，此处列方向）：

1. **视觉层次**：背景从纯色升级为柔和渐变/微光晕；顶栏、侧栏、卡片做真实的「玻璃」质感（半透明 + 模糊 + 高光边），深色下更出效果；
2. **色彩体系**：在现有主色 `#3b66d9` 基础上建立「品牌渐变 + 模块主题色」体系（首页/记账/自媒体/健身…各有辨识色），让界面有主次、有情绪；
3. **字体排版**：标题/正文/数字的层级更分明，数字用等宽数字（对齐美观），品牌字重与字距统一；
4. **动效**：页面切换淡入、卡片 hover 抬升、弹窗缩放进场、按钮按压反馈；尊重系统「减弱动态效果」设置；
5. **细节质感**：空状态配图（内联 SVG，不联网）、聚焦环、选中态、图标统一线性风格、卡片 hover 高光。

**硬约束（写死在需求里）：**
- 不改 DOM 结构与既有 class 名 —— 46 个测试文件的选择器依赖它们；
- 不引入任何在线资源（字体、图标、CDN）—— 保持断网可用；
- style.css 131KB 全站一套，改动走「设计令牌（CSS 变量）增量覆盖」策略，不整文件重写。

### 主线三：体验闭环（配套小改动）

桌面化会顺带暴露一些「浏览器里没感觉、窗口里很显眼」的问题，一并纳入：

- 应用窗口尺寸与最小尺寸设定（首屏 1280×860 左右，可缩放）；
- 窗口图标复用现有 `小李.ico`；
- 关闭窗口的确认/兜底（数据每次操作即保存，正常关闭不丢数据）；
- 设置页「服务地址」等浏览器语境文案，在桌面模式下弱化或隐藏（可选，低优先）。

## 3. 优先级与里程碑

| 里程碑 | 内容 | 验收 |
| --- | --- | --- |
| M1 桌面外壳 | pywebview 窗口跑通 + 不弹黑窗口 + 回退机制 | 双击启动只见小李窗口；删掉 pywebview 仍能浏览器模式 |
| M2 视觉升级第一波 | 背景/顶栏/侧栏/卡片质感 + 模块主题色 + 基础动效 | 明暗两套截图对比有明显质感提升 |
| M3 视觉升级第二波 | 空状态/聚焦/选中/弹窗动效等细节 + 全站走查 | 11 个模块逐个过一遍无视觉死角 |
| M4 回归与交付 | 46 测试全绿 + 自检全绿 + 同步到日常用那份 | 日常双击启动体验即为成品 |

M1 与 M2 可并行推进（桌面壳与 CSS 互不依赖），M3 依赖 M2 的令牌体系落地，M4 收尾。

## 4. 底线与不做

**不做（本轮明确排除）：**
- 不做联网功能（保持「零外链、不联网」定位，桌面窗口只是本地页面容器）；
- 不做手机端 / 部署 / 云同步；
- 不做系统托盘常驻（窗口关了程序就退出，符合现在「关窗即停」的心智）；
- 不做 frameless 自定义标题栏（第一版用系统标题栏，稳；自定义标题栏涉及 JS 拖拽 + 窗口控制 API，留作后续可选）；
- 不改数据格式、不迁移数据、不动数据集功能。

**底线（任何一步都不能破）：**
- `tests\` 46 个测试文件全绿，`自检.py` 全绿；
- 断网可用；
- 双击永远能用（任一环节缺依赖都回退到浏览器模式）；
- 数据安全性：多窗口 409 防串、版本号、文件锁、数据集隔离 —— 全部保持原样。

## 5. 待拍板事项

1. **窗口默认尺寸**：1280×860 合适吗？还是偏好更宽（1440×900）？
2. **关闭窗口**：直接退出（推荐），还是最小化到托盘（本轮不做）？
3. **UI 风格**：走「深色优先的高级感」（推荐，玻璃质感在深色下最出效果、也最像现代桌面软件），还是「浅色为主的清爽感」？两种都会做，但决定主视觉重心。
4. **主色**：保留现在的蓝色 `#3b66d9` 作为品牌色扩展渐变，还是换一个更有个性的主色调（如靛紫/青绿）？

确认后拆成需求文档与实施计划。
